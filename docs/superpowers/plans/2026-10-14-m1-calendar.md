# M1: 모노레포 뼈대와 calendar 패키지 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 양력과 한국 음력(dangi, KASI 1900~2050)을 오가는 날짜 값·역법 패키지 `@lunisolar-picker/calendar`를 모노레포 뼈대와 함께 만든다.

**Architecture:** 모든 날짜 계산은 epoch day 정수로 한다. 역법은 `CalendarSystem` 인터페이스 구현체(`gregory`, `dangi`)로 다룬다. 공개 값은 Temporal 형식 문자열(`2026-10-14`, `2026-10-14[u-ca=dangi]`)이며 브랜드 타입으로 보호한다. 음력은 KASI OpenAPI 원본을 한 번 수집해 커밋하고, 그 원본에서 압축 정수 표를 생성해 `./dangi` subpath에 내장한다.

**Tech Stack:** pnpm workspace, TypeScript 6.0.3, tsdown 0.23.1, vitest 5.0.4, fast-check 4.10.2, Biome 2.5.15, dependency-cruiser 18.6.0, tsx 4.23.15, esbuild 0.28.2, publint 0.3.25, @arethetypeswrong/cli 0.18.5

**Spec:** `docs/superpowers/specs/2026-10-14-lunisolar-picker-design.md` (특히 3장 아키텍처, 4장 값 모델, 5장 역법, 11장 테스트, 12장 빌드)

**후속 계획:** M2(core), M3(react 기반·theme·입력 부품), M4(달력 부품·완성형), M5(문서·배포·CI)는 이 계획이 끝난 뒤 앞 단계의 실제 인터페이스를 보고 각각 따로 쓴다.

## Global Constraints

- 개발 환경: Node `>=24.11.0`(로컬 24.14.0), pnpm `11.28.2`(로컬에 설치된 버전, 형제 프로젝트와 동일). 소비자 Node 기준선 `>=22.12.0`
- 의존성은 **정확한 버전만** 쓴다. 범위(`^`, `~`, `latest`) 금지. 위 Tech Stack 버전 그대로
- TypeScript는 7.0.2가 최신이지만 **6.0.3**을 쓴다. 7은 기존 JS API(`require('typescript')`)를 내보내지 않아 dependency-cruiser 같은 도구가 TS를 해석하지 못할 위험이 있다
- ESM 전용. `"type": "module"`, `"sideEffects": false`
- calendar 패키지는 **런타임 의존성 0**. `src/`는 `node:` 모듈과 npm 패키지를 import하지 않는다(테스트 파일 제외)
- 루트 진입점(`src/` 중 `src/dangi/` 밖)은 `src/dangi/`를 import하지 않는다. 음력을 안 쓰는 번들에 음력 표가 들어가면 안 된다(스펙 5.1)
- 양력 지원 범위: 서기 1~9999년(proleptic Gregorian). 음력: KASI 데이터 기준 음력 1900년 1월 1일부터 수집된 마지막 날까지
- 공개 문자열 형식(스펙 4.1): 날짜 `YYYY-MM-DD`, 음력 입력 날짜 `YYYY-MM-DD[u-ca=dangi]`, 시간 `HH:mm`(`24:00`은 `isEndOfDayAllowed`일 때만), 월 `YYYY-MM`. 그 밖의 형식은 모두 거부
- `ValidationReason`(스펙 5.5): `'invalid-date' | 'invalid-time' | 'incomplete' | 'before-min' | 'after-max' | 'disabled-date' | 'outside-calendar-range' | 'range-too-short' | 'range-too-long' | 'range-includes-disabled'`
- 오류: 예상 가능한 실패는 `Result`로 돌려주고, 잘못된 API 호출만 `LunisolarPickerError`(`RangeError` 상속)를 던진다. 오류를 조용히 삼키지 않는다
- 이름 규칙: 약어 금지(id, api 등 업계 표준 제외), boolean은 `is/has/can/should` 접두사, `process/handle/manage/do/execute` 같은 모호한 동사 금지, 컬렉션은 복수형
- 주석은 WHY(Goal/Constraint/Side effect)만 한국어로 쓴다. 코드 설명·구분선·주석 처리된 코드 금지
- 테스트: 대상 파일 옆 `*.test.ts`, `describe` 계층으로 맥락, 테스트 이름은 동작 서술(영어), Given-When-Then, 고정 값 사용. fast-check는 고정 시드(`vitest.setup.ts`)
- 커밋: 한국어 Conventional Commits(목적 중심 제목, 명사형 종결), AI 공동작성자 트레일러 없음. 이 환경의 훅은 사용자가 승인한 커밋에 `ALLOW_COMMIT=1` 접두를 요구한다
- `just check`(typecheck, lint, 의존 경계)와 `just test`가 각 Task 끝에서 통과해야 한다

## Review Focus

1. **설날 전 양력 1~2월 날짜**: 이전 음력 해의 12월로 귀속되어야 한다(예: 2026-02-16 → 음력 2025년 12월 29일). Task 8에서 고정
2. **지원 범위 바로 바깥**: 1900-01-30(음력 1899년)과 마지막 수집일 다음 날은 `'outside-calendar-range'`여야 하고, 경계 당일은 정상이어야 한다. Task 8에서 고정
3. **비정규 문자열**: 앞뒤 공백, 대문자 표기(`[U-CA=DANGI]`), 확장 연도(`+002026-…`), 중복 표기, `[u-ca=gregory]`, 0을 안 채운 값은 모두 거부되어야 한다. Task 3에서 고정
4. **1970년 이전과 세기 윤년**: 음수 epoch day, 1900년(평년)과 2000년(윤년) 규칙이 맞아야 한다. Task 1에서 고정
5. **KASI 응답 이상**: 인증키 오류 응답, 한 달 중 일부만 온 응답, 달 사이 공백이 있으면 표를 만들지 않고 실패해야 한다. Task 5·6에서 고정

`packages/calendar/src/epoch-day.test.ts`:
```ts
import fc from 'fast-check';
import { describe, expect, it } from 'vitest';
import {
  type EpochDay,
  civilFromEpochDay,
  daysInGregorianMonth,
  epochDayFromCivil,
  isGregorianLeapYear,
  weekdayOf,
} from './epoch-day';

const MILLISECONDS_PER_DAY = 86_400_000;
const FIRST_SUPPORTED_EPOCH_DAY = -719_162;
const LAST_SUPPORTED_EPOCH_DAY = 2_932_896;

function platformEpochDay(year: number, month: number, day: number): number {
  const date = new Date(0);
  date.setUTCFullYear(year, month - 1, day);
  return Math.round(date.getTime() / MILLISECONDS_PER_DAY);
}

describe('epoch-day', () => {
  describe('epochDayFromCivil', () => {
    it.each([
      [1970, 1, 1, 0],
      [1969, 12, 31, -1],
      [1900, 1, 1, -25_567],
      [2000, 2, 29, 11_016],
      [2000, 3, 1, 11_017],
      [2026, 10, 14, 20_740],
      [1, 1, 1, FIRST_SUPPORTED_EPOCH_DAY],
      [9999, 12, 31, LAST_SUPPORTED_EPOCH_DAY],
    ])('maps %i-%i-%i to epoch day %i', (year, month, day, expected) => {
      expect(epochDayFromCivil(year, month, day)).toBe(expected);
    });

    it('agrees with the platform UTC calendar for every year from 1 to 9999', () => {
      fc.assert(
        fc.property(
          fc.integer({ min: 1, max: 9999 }),
          fc.integer({ min: 1, max: 12 }),
          fc.integer({ min: 1, max: 28 }),
          (year, month, day) => epochDayFromCivil(year, month, day) === platformEpochDay(year, month, day),
        ),
      );
    });
  });

  describe('civilFromEpochDay', () => {
    it('reads negative epoch days before 1970 as the matching civil date', () => {
      expect(civilFromEpochDay(-25_567 as EpochDay)).toEqual({ year: 1900, month: 1, day: 1 });
    });

    it('round-trips every epoch day between year 1 and 9999', () => {
      fc.assert(
        fc.property(fc.integer({ min: FIRST_SUPPORTED_EPOCH_DAY, max: LAST_SUPPORTED_EPOCH_DAY }), (value) => {
          const { year, month, day } = civilFromEpochDay(value as EpochDay);
          return epochDayFromCivil(year, month, day) === value;
        }),
      );
    });
  });

  describe('weekdayOf', () => {
    it.each([
      [0, 4],
      [-1, 3],
      [-25_567, 1],
      [20_740, 3],
      [LAST_SUPPORTED_EPOCH_DAY, 5],
    ])('returns weekday %i → %i with Sunday as 0', (epochDay, expected) => {
      expect(weekdayOf(epochDay as EpochDay)).toBe(expected);
    });
  });

  describe('Gregorian leap rules', () => {
    it.each([
      [1900, false],
      [2000, true],
      [2024, true],
      [2026, false],
    ])('treats %i as leap year: %s', (year, expected) => {
      expect(isGregorianLeapYear(year)).toBe(expected);
    });

    it.each([
      [1900, 2, 28],
      [2000, 2, 29],
      [2026, 4, 30],
      [2026, 12, 31],
    ])('gives %i-%i %i days', (year, month, expected) => {
      expect(daysInGregorianMonth(year, month)).toBe(expected);
    });
  });
});
```

// Goal: 비교·범위·역법 변환을 모두 정수 하나로 계산하기 위한 정규 표현 (스펙 4.3)
export type EpochDay = number & { readonly [epochDayBrand]: true };

export interface CivilDate {
  readonly year: number;
  readonly month: number;
  readonly day: number;
}

const DAYS_PER_ERA = 146_097;
const DAYS_FROM_ERA_START_TO_EPOCH = 719_468;
const YEARS_PER_ERA = 400;
const DAYS_PER_WEEK = 7;
const EPOCH_WEEKDAY = 4;
const GREGORIAN_MONTH_DAYS = [31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31] as const;

// Constraint: 3월 시작 연도로 바꿔 윤일을 연말에 두는 Howard Hinnant의 days_from_civil 알고리즘. 음수 연도·epoch 이전 날짜도 정확해야 함
export function epochDayFromCivil(year: number, month: number, day: number): EpochDay {
  const marchBasedYear = month <= 2 ? year - 1 : year;
  const era = Math.floor(marchBasedYear / YEARS_PER_ERA);
  const yearOfEra = marchBasedYear - era * YEARS_PER_ERA;
  const marchBasedMonth = month > 2 ? month - 3 : month + 9;
  const dayOfYear = Math.floor((153 * marchBasedMonth + 2) / 5) + day - 1;
  const dayOfEra = yearOfEra * 365 + Math.floor(yearOfEra / 4) - Math.floor(yearOfEra / 100) + dayOfYear;
  return (era * DAYS_PER_ERA + dayOfEra - DAYS_FROM_ERA_START_TO_EPOCH) as EpochDay;
}

export function civilFromEpochDay(epochDay: EpochDay): CivilDate {
  const shiftedDay = epochDay + DAYS_FROM_ERA_START_TO_EPOCH;
  const era = Math.floor(shiftedDay / DAYS_PER_ERA);
  const dayOfEra = shiftedDay - era * DAYS_PER_ERA;
  const yearOfEra = Math.floor(
    (dayOfEra - Math.floor(dayOfEra / 1460) + Math.floor(dayOfEra / 36_524) - Math.floor(dayOfEra / 146_096)) / 365,
  );
  const dayOfYear = dayOfEra - (365 * yearOfEra + Math.floor(yearOfEra / 4) - Math.floor(yearOfEra / 100));
  const marchBasedMonth = Math.floor((5 * dayOfYear + 2) / 153);
  const day = dayOfYear - Math.floor((153 * marchBasedMonth + 2) / 5) + 1;
  const month = marchBasedMonth < 10 ? marchBasedMonth + 3 : marchBasedMonth - 9;
  const year = yearOfEra + era * YEARS_PER_ERA + (month <= 2 ? 1 : 0);
  return { year, month, day };
}

export function weekdayOf(epochDay: EpochDay): number {
  return (((epochDay + EPOCH_WEEKDAY) % DAYS_PER_WEEK) + DAYS_PER_WEEK) % DAYS_PER_WEEK;
}

export function isGregorianLeapYear(year: number): boolean {
  return (year % 4 === 0 && year % 100 !== 0) || year % 400 === 0;
}

export function daysInGregorianMonth(year: number, month: number): number {
  if (month === 2 && isGregorianLeapYear(year)) return 29;
  return GREGORIAN_MONTH_DAYS[month - 1] ?? 0;
}

import { LunisolarPickerError } from './errors';

type MonthNumberCode = '01' | '02' | '03' | '04' | '05' | '06' | '07' | '08' | '09' | '10' | '11' | '12';

// Goal: Temporal monthCode와 같은 표기. 윤달은 L 접미사 (예: M04L = 윤4월)
export type MonthCode = `M${MonthNumberCode}` | `M${MonthNumberCode}L`;

export interface MonthCodeParts {
  readonly month: number;
  readonly isLeapMonth: boolean;
}

const MONTH_CODE_PATTERN = /^M(0[1-9]|1[0-2])(L?)$/;
const FIRST_MONTH = 1;
const LAST_MONTH = 12;

export function isMonthCode(value: string): value is MonthCode {
  return MONTH_CODE_PATTERN.test(value);
}

export function toMonthCode(month: number, isLeapMonth: boolean): MonthCode {
  if (!Number.isInteger(month) || month < FIRST_MONTH || month > LAST_MONTH) {
    throw new LunisolarPickerError(`month must be an integer from 1 to 12, received ${month}`);
  }
  return `M${String(month).padStart(2, '0')}${isLeapMonth ? 'L' : ''}` as MonthCode;
}

export function parseMonthCode(monthCode: MonthCode): MonthCodeParts {
  const match = MONTH_CODE_PATTERN.exec(monthCode);
  if (!match) throw new LunisolarPickerError(`invalid month code: ${monthCode}`);
  return { month: Number(match[1]), isLeapMonth: match[2] === 'L' };
}

import type { CalendarSystem, SupportedRange } from './calendar-system';
import { civilFromEpochDay, daysInGregorianMonth, epochDayFromCivil } from './epoch-day';
import { LunisolarPickerError } from './errors';
import { type MonthCode, isMonthCode, parseMonthCode, toMonthCode } from './month-code';
import { err, ok } from './result';

const FIRST_YEAR = 1;
const LAST_YEAR = 9999;
const MONTHS_PER_YEAR = 12;

const GREGORIAN_MONTH_CODES: readonly MonthCode[] = Array.from({ length: MONTHS_PER_YEAR }, (_, index) =>
  toMonthCode(index + 1, false),
);

const SUPPORTED_RANGE: SupportedRange = {
  min: epochDayFromCivil(FIRST_YEAR, 1, 1),
  max: epochDayFromCivil(LAST_YEAR, 12, 31),
};

function isSupportedYear(year: number): boolean {
  return Number.isInteger(year) && year >= FIRST_YEAR && year <= LAST_YEAR;
}

function assertSupportedYear(year: number): void {
  if (!isSupportedYear(year)) {
    throw new LunisolarPickerError(`gregory supports years ${FIRST_YEAR}-${LAST_YEAR}, received ${year}`);
  }
}

export const gregory: CalendarSystem = {
  id: 'gregory',
  supportedRange: SUPPORTED_RANGE,
  monthsInYear(year) {
    assertSupportedYear(year);
    return GREGORIAN_MONTH_CODES;
  },
  daysInMonth(year, monthCode) {
    assertSupportedYear(year);
    const { month, isLeapMonth } = parseMonthCode(monthCode);
    if (isLeapMonth) throw new LunisolarPickerError(`gregory has no leap month: ${monthCode}`);
    return daysInGregorianMonth(year, month);
  },
  toEpochDay({ year, monthCode, day }) {
    if (!isSupportedYear(year)) return err('outside-calendar-range');
    if (!isMonthCode(monthCode)) return err('invalid-date');
    const { month, isLeapMonth } = parseMonthCode(monthCode);
    const isValidDay = Number.isInteger(day) && day >= 1 && day <= daysInGregorianMonth(year, month);
    if (isLeapMonth || !isValidDay) return err('invalid-date');
    return ok(epochDayFromCivil(year, month, day));
  },
  fromEpochDay(epochDay) {
    if (epochDay < SUPPORTED_RANGE.min || epochDay > SUPPORTED_RANGE.max) return err('outside-calendar-range');
    const { year, month, day } = civilFromEpochDay(epochDay);
    return ok({ year, monthCode: toMonthCode(month, false), day });
  },
};

import { type CalendarId, type CalendarSystem, type DateFields, isWithinSupportedRange } from '../calendar-system';
import { type EpochDay, civilFromEpochDay, epochDayFromCivil } from '../epoch-day';
import { padNumber } from '../format-number';
import { gregory } from '../gregorian';
import { toMonthCode } from '../month-code';
import { type Result, err, ok } from '../result';
import type { ValidationReason } from '../validation-reason';

declare const dateStringBrand: unique symbol;

// Goal: parseDate·formatDate를 거친 정규 문자열만 이 타입이 됨. 같은 날짜·같은 역법이면 항상 === 로 같음 (스펙 4.2)
export type DateString = string & { readonly [dateStringBrand]: true };

export interface ParsedDate extends DateFields {
  readonly calendar: CalendarId;
  readonly epochDay: EpochDay;
  readonly value: DateString;
}

export interface ParseDateOptions {
  readonly calendars?: readonly CalendarSystem[];
}

const DATE_STRING_PATTERN = /^(\d{4})-(\d{2})-(\d{2})(?:\[u-ca=([a-z]+)\])?$/;
const YEAR_DIGITS = 4;
const MONTH_DIGITS = 2;
const ISO_DATE_LENGTH = 10;
const YEAR_END = 4;
const MONTH_START = 5;
const MONTH_END = 7;
const DAY_START = 8;
const ANNOTATION_PREFIX_LENGTH = '[u-ca='.length;

export function parseDate(input: string, options: ParseDateOptions = {}): Result<ParsedDate, ValidationReason> {
  const match = DATE_STRING_PATTERN.exec(input);
  if (!match) return err('invalid-date');
  const [, yearText = '', monthText = '', dayText = '', annotatedCalendarId] = match;
  const epochDay = isoPartsToEpochDay(Number(yearText), Number(monthText), Number(dayText));
  if (!epochDay.isOk) return epochDay;
  const calendar = resolveAnnotatedCalendar(annotatedCalendarId, options.calendars ?? []);
  if (!calendar) return err('invalid-date');
  const fields = calendar.fromEpochDay(epochDay.value);
  if (!fields.isOk) return fields;
  return ok({ ...fields.value, calendar: calendar.id, epochDay: epochDay.value, value: input as DateString });
}

export function formatDate(epochDay: EpochDay, calendar: CalendarSystem = gregory): Result<DateString, ValidationReason> {
  if (!isWithinSupportedRange(gregory, epochDay) || !isWithinSupportedRange(calendar, epochDay)) {
    return err('outside-calendar-range');
  }
  const { year, month, day } = civilFromEpochDay(epochDay);
  const isoDate = `${padNumber(year, YEAR_DIGITS)}-${padNumber(month, MONTH_DIGITS)}-${padNumber(day, MONTH_DIGITS)}`;
  return ok((calendar.id === gregory.id ? isoDate : `${isoDate}[u-ca=${calendar.id}]`) as DateString);
}

export function epochDayOf(value: DateString): EpochDay {
  return epochDayFromCivil(
    Number(value.slice(0, YEAR_END)),
    Number(value.slice(MONTH_START, MONTH_END)),
    Number(value.slice(DAY_START, ISO_DATE_LENGTH)),
  );
}

export function calendarIdOf(value: DateString): CalendarId {
  if (value.length === ISO_DATE_LENGTH) return gregory.id;
  return value.slice(ISO_DATE_LENGTH + ANNOTATION_PREFIX_LENGTH, -1) as CalendarId;
}

export function isSameDay(first: DateString, second: DateString): boolean {
  return first.slice(0, ISO_DATE_LENGTH) === second.slice(0, ISO_DATE_LENGTH);
}

function isoPartsToEpochDay(year: number, month: number, day: number): Result<EpochDay, ValidationReason> {
  if (year === 0 || month < 1 || month > 12) return err('invalid-date');
  const epochDay = gregory.toEpochDay({ year, monthCode: toMonthCode(month, false), day });
  return epochDay.isOk ? epochDay : err('invalid-date');
}

// Constraint: 양력은 표기 없이만 쓰는 것이 정규 형식이라 [u-ca=gregory]는 거부함
function resolveAnnotatedCalendar(
  annotatedCalendarId: string | undefined,
  calendars: readonly CalendarSystem[],
): CalendarSystem | undefined {
  if (annotatedCalendarId === undefined) return gregory;
  if (annotatedCalendarId === gregory.id) return undefined;
  return calendars.find((calendar) => calendar.id === annotatedCalendarId);
}

}

const TIME_STRING_PATTERN = /^(\d{2}):(\d{2})$/;
const END_OF_DAY_HOUR = 24;
const LAST_HOUR = 23;
const LAST_MINUTE = 59;
const TIME_PART_DIGITS = 2;

export function parseTime(input: string, options: TimeOptions = {}): Result<ParsedTime, ValidationReason> {
  const match = TIME_STRING_PATTERN.exec(input);
  if (!match) return err('invalid-time');
  return formatParsedTime(Number(match[1]), Number(match[2]), options);
}

export function formatTime(hour: number, minute: number, options: TimeOptions = {}): Result<TimeString, ValidationReason> {
  const parsed = formatParsedTime(hour, minute, options);
  return parsed.isOk ? ok(parsed.value.value) : parsed;
}

function formatParsedTime(hour: number, minute: number, options: TimeOptions): Result<ParsedTime, ValidationReason> {
  if (!isValidTime(hour, minute, options.isEndOfDayAllowed === true)) return err('invalid-time');
  const value = `${padNumber(hour, TIME_PART_DIGITS)}:${padNumber(minute, TIME_PART_DIGITS)}` as TimeString;
  return ok({ hour, minute, value });
}

// Constraint: 24:00은 하루의 끝을 뜻하는 표기라 분이 0일 때만 허용하고 다음 날로 바꾸지 않음 (스펙 4.2)
function isValidTime(hour: number, minute: number, isEndOfDayAllowed: boolean): boolean {
  if (!Number.isInteger(hour) || !Number.isInteger(minute)) return false;
  if (hour === END_OF_DAY_HOUR) return isEndOfDayAllowed && minute === 0;
  return hour >= 0 && hour <= LAST_HOUR && minute >= 0 && minute <= LAST_MINUTE;
}

import type { ValidationReason } from '../validation-reason';
import { type DateString, calendarIdOf, epochDayOf } from './date-string';

export interface DateRangeValue {
  readonly start: DateString;
  readonly end: DateString | null;
}

// Constraint: 양 끝은 같은 역법이어야 하고 start가 end보다 늦으면 순서를 바꿈 (스펙 4.2 범위 불변식)
export function normalizeDateRange(start: DateString, end: DateString | null): Result<DateRangeValue, ValidationReason> {
  if (end === null) return ok({ start, end });
  if (calendarIdOf(start) !== calendarIdOf(end)) return err('invalid-date');
  return ok(epochDayOf(end) < epochDayOf(start) ? { start: end, end: start } : { start, end });
}

export function isSameRange(first: DateRangeValue | null, second: DateRangeValue | null): boolean {
  if (first === null || second === null) return first === second;
  return first.start === second.start && first.end === second.end;
}

import { type EpochDay, epochDayFromCivil } from '../epoch-day';
import { LunisolarPickerError } from '../errors';
import { type DangiYearRecord, expectedMonthCount } from './year-record';

// Goal: 1900~2050년 표를 gzip 1KB 안팎에 담기 위해 한 해를 정수 하나로 압축함 (스펙 5.3)
// 비트 배치: [0..5] 1월 1일부터 설날까지 일수, [6..18] 달별 대(30)·소(29), [19..22] 윤달 번호, [23..26] 알려진 달 수
const NEW_YEAR_OFFSET_BITS = 6;
const MONTH_LENGTH_BITS = 13;
const LEAP_MONTH_BITS = 4;
const MONTH_COUNT_BITS = 4;
const MONTH_LENGTH_SHIFT = NEW_YEAR_OFFSET_BITS;
const LEAP_MONTH_SHIFT = MONTH_LENGTH_SHIFT + MONTH_LENGTH_BITS;
const MONTH_COUNT_SHIFT = LEAP_MONTH_SHIFT + LEAP_MONTH_BITS;
const NEW_YEAR_OFFSET_MASK = (1 << NEW_YEAR_OFFSET_BITS) - 1;
const MONTH_LENGTH_MASK = (1 << MONTH_LENGTH_BITS) - 1;
const LEAP_MONTH_MASK = (1 << LEAP_MONTH_BITS) - 1;
const MONTH_COUNT_MASK = (1 << MONTH_COUNT_BITS) - 1;
const LONG_MONTH_DAYS = 30;
const SHORT_MONTH_DAYS = 29;
const LAST_LEAP_MONTH = 12;

export function encodeDangiYear(record: DangiYearRecord): number {
  const newYearOffset = record.newYearEpochDay - epochDayFromCivil(record.year, 1, 1);
  assertEncodable(record, newYearOffset);
  const monthLengthBits = record.monthLengths.reduce(
    (bits, days, index) => (days === LONG_MONTH_DAYS ? bits | (1 << index) : bits),
    0,
  );
  return (
    newYearOffset |
    (monthLengthBits << MONTH_LENGTH_SHIFT) |
    (record.leapMonth << LEAP_MONTH_SHIFT) |
    (record.monthLengths.length << MONTH_COUNT_SHIFT)
  );
}

export function decodeDangiYear(year: number, encoded: number): DangiYearRecord {
  const newYearOffset = encoded & NEW_YEAR_OFFSET_MASK;
  const monthLengthBits = (encoded >> MONTH_LENGTH_SHIFT) & MONTH_LENGTH_MASK;
  const leapMonth = (encoded >> LEAP_MONTH_SHIFT) & LEAP_MONTH_MASK;
  const monthCount = (encoded >> MONTH_COUNT_SHIFT) & MONTH_COUNT_MASK;
  return {
    year,
    newYearEpochDay: (epochDayFromCivil(year, 1, 1) + newYearOffset) as EpochDay,
    leapMonth,
    monthLengths: Array.from({ length: monthCount }, (_, index) =>
      (monthLengthBits >> index) & 1 ? LONG_MONTH_DAYS : SHORT_MONTH_DAYS,
    ),
  };
}

function assertEncodable(record: DangiYearRecord, newYearOffset: number): void {
  const problems = [
    newYearOffset < 0 || newYearOffset > NEW_YEAR_OFFSET_MASK ? `new year offset ${newYearOffset} is outside 0-63` : '',
    !Number.isInteger(record.leapMonth) || record.leapMonth < 0 || record.leapMonth > LAST_LEAP_MONTH
      ? `leap month ${record.leapMonth} is outside 0-12`
      : '',
    record.monthLengths.length === 0 || record.monthLengths.length > expectedMonthCount(record)
      ? `month count ${record.monthLengths.length} does not fit leap month ${record.leapMonth}`
      : '',
    record.monthLengths.some((days) => days !== LONG_MONTH_DAYS && days !== SHORT_MONTH_DAYS)
      ? `month lengths must be 29 or 30: ${record.monthLengths.join(',')}`
      : '',
  ].filter((problem) => problem !== '');
  if (problems.length > 0) {
    throw new LunisolarPickerError(`cannot encode lunar year ${record.year}: ${problems.join('; ')}`);
  }
}

function assertSuccessfulResponse(xml: string): void {
  const resultCode = findTag(xml, 'resultCode');
  if (resultCode === SUCCESS_RESULT_CODE) return;
  if (resultCode !== undefined) throw new KasiApiError(resultCode, findTag(xml, 'resultMsg') ?? 'no resultMsg');
  const gatewayCode = findTag(xml, 'returnReasonCode') ?? 'gateway';
  const gatewayReason = findTag(xml, 'returnAuthMsg') ?? findTag(xml, 'errMsg');
  throw new KasiApiError(gatewayCode, gatewayReason ?? `unrecognized response: ${xml.slice(0, ERROR_SNIPPET_LENGTH)}`);
}

function findTag(xml: string, tag: string): string | undefined {
  return new RegExp(`<${tag}>([^<]*)</${tag}>`).exec(xml)?.[1]?.trim();
}

function readTag(itemXml: string, tag: string): string {
  const value = findTag(itemXml, tag);
  if (value === undefined || value === '') {
    throw new Error(`KASI item is missing <${tag}>: ${itemXml.slice(0, ERROR_SNIPPET_LENGTH)}`);
  }
  return value;
}

function readInteger(itemXml: string, tag: string): number {
  const text = readTag(itemXml, tag);
  const value = Number(text);
  if (!Number.isInteger(value)) throw new Error(`KASI item <${tag}> is not an integer: "${text}"`);
  return value;
}

function readLeapFlag(itemXml: string): boolean {
  const flag = readTag(itemXml, 'lunLeapmonth');
  if (flag === '윤') return true;
  if (flag === '평') return false;
  throw new Error(`unexpected lunLeapmonth value "${flag}"`);

import { epochDayFromCivil } from '../../src/epoch-day';
import { isoDateToEpochDay, toIsoDate } from './iso-date';
import type { KasiDayItem, KasiMonthStart } from './kasi-types';

const FIRST_LUNAR_DAY = 1;
const VALID_MONTH_LENGTHS: ReadonlySet<number> = new Set([29, 30]);

export function extractMonthStarts(items: readonly KasiDayItem[]): KasiMonthStart[] {
  const monthStarts = [...items]
    .sort((first, second) => solarEpochDayOf(first) - solarEpochDayOf(second))
    .filter((item) => item.lunarDay === FIRST_LUNAR_DAY)
    .map((item) => ({
      lunarYear: item.lunarYear,
      lunarMonth: item.lunarMonth,
      isLeapMonth: item.isLeapMonth,
      days: item.lunarMonthDays,
      solarStart: toIsoDate(item.solarDate),
    }));
  assertMonthLengths(monthStarts);
  assertContiguous(monthStarts);
  return monthStarts;
}

function solarEpochDayOf(item: KasiDayItem): number {
  return epochDayFromCivil(item.solarDate.year, item.solarDate.month, item.solarDate.day);
}

function assertMonthLengths(monthStarts: readonly KasiMonthStart[]): void {
  const invalid = monthStarts.find((start) => !VALID_MONTH_LENGTHS.has(start.days));
  if (invalid) throw new Error(`lunar month starting ${invalid.solarStart} has ${invalid.days} days; expected 29 or 30`);
}

// Constraint: 한 달이라도 빠지면 그 뒤 모든 날짜가 어긋나므로 시작일 간격이 직전 달 길이와 정확히 같아야 함
function assertContiguous(monthStarts: readonly KasiMonthStart[]): void {
  monthStarts.slice(1).forEach((current, index) => {
    const previous = monthStarts[index];
    if (!previous) return;
    const expectedStart = isoDateToEpochDay(previous.solarStart) + previous.days;
    if (isoDateToEpochDay(current.solarStart) !== expectedStart) {
      throw new Error(`lunar month starting ${current.solarStart} does not follow ${previous.solarStart} (+${previous.days} days)`);
    }
  });
}

const FIRST_SOLAR_MONTH: SolarMonth = { year: 1900, month: 1 };
// Goal: 음력 2050년 마지막 달은 양력 2051년에 걸침. KASI가 제공하는 데까지 받으려고 2051년 초까지 시도하고, 범위를 벗어나는 첫 달에서 멈춤
const LAST_SOLAR_MONTH_TO_TRY: SolarMonth = { year: 2051, month: 3 };
const LAST_GUARANTEED_YEAR = 2050;
const ROWS_PER_PAGE = 31;
const REQUEST_INTERVAL_MILLISECONDS = 120;
const MAX_ATTEMPTS = 3;
const RETRY_BASE_DELAY_MILLISECONDS = 1000;

const packageRoot = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '../..');
const cacheDirectory = path.join(packageRoot, '.cache/kasi');
const outputPath = path.join(packageRoot, 'data/kasi-dangi-months.json');

async function collectKasiData(): Promise<void> {
  const serviceKey = readServiceKey();
  await mkdir(cacheDirectory, { recursive: true });
  const items: KasiDayItem[] = [];
  let lastCollectedMonth: SolarMonth | undefined;
  for (const solarMonth of listSolarMonths(FIRST_SOLAR_MONTH, LAST_SOLAR_MONTH_TO_TRY)) {
    const monthItems = await collectMonthItems(serviceKey, solarMonth);
    if (monthItems === null) break;
    items.push(...monthItems);
    lastCollectedMonth = solarMonth;
  }
  if (!lastCollectedMonth) throw new Error('KASI returned no data at all');
  await writeDataFile(items, lastCollectedMonth);
}

function readServiceKey(): string {
  const serviceKey = process.env[SERVICE_KEY_ENVIRONMENT_VARIABLE];
  if (!serviceKey) {
    throw new Error(
      `${SERVICE_KEY_ENVIRONMENT_VARIABLE} is not set. data.go.kr에서 '한국천문연구원_음양력 정보' 활용신청 후 일반 인증키(Decoding)를 넣어 주세요.`,
    );
  }
  return serviceKey;
}

function listSolarMonths(first: SolarMonth, last: SolarMonth): SolarMonth[] {
  const solarMonths: SolarMonth[] = [];
  for (let year = first.year; year <= last.year; year += 1) {
    const firstMonth = year === first.year ? first.month : 1;
    const lastMonth = year === last.year ? last.month : 12;
    for (let month = firstMonth; month <= lastMonth; month += 1) solarMonths.push({ year, month });
  }
  return solarMonths;
}

// Goal: 2050년까지는 실패를 그대로 던지고, 그 뒤는 KASI 제공 범위 끝으로 보고 수집을 멈춤(null)
async function collectMonthItems(serviceKey: string, solarMonth: SolarMonth): Promise<KasiDayItem[] | null> {
  const isBeyondGuaranteedRange = solarMonth.year > LAST_GUARANTEED_YEAR;
  try {
    const items = parseKasiDayItems(await readMonthXml(serviceKey, solarMonth));
    if (isBeyondGuaranteedRange && items.length === 0) return null;
    assertWholeMonth(items, solarMonth);
    return items;
  } catch (error) {
    if (isBeyondGuaranteedRange && error instanceof KasiApiError) {
      console.info(`KASI coverage ends before ${labelOf(solarMonth)} (${error.message})`);
      return null;
    }
    throw error;
  }
}

async function readMonthXml(serviceKey: string, solarMonth: SolarMonth): Promise<string> {
  const cachePath = path.join(cacheDirectory, `${labelOf(solarMonth)}.xml`);
  if (await isReadable(cachePath)) return readFile(cachePath, 'utf8');
  const xml = await fetchMonthXml(serviceKey, solarMonth);
  parseKasiDayItems(xml);
  await writeFile(cachePath, xml);
  await delay(REQUEST_INTERVAL_MILLISECONDS);
  return xml;
}

async function isReadable(filePath: string): Promise<boolean> {
  try {
    await access(filePath);
    return true;
  } catch {
    return false;
  }
}

// Constraint: URL에는 인증키가 들어가므로 로그·오류 메시지에 URL을 남기지 않음
async function fetchMonthXml(serviceKey: string, solarMonth: SolarMonth): Promise<string> {
  const url = new URL(ENDPOINT);
  url.search = new URLSearchParams({
    serviceKey,
    solYear: String(solarMonth.year),
    solMonth: String(solarMonth.month).padStart(2, '0'),
    numOfRows: String(ROWS_PER_PAGE),
    pageNo: '1',
  }).toString();
  for (let attempt = 1; ; attempt += 1) {
    try {
      const response = await fetch(url);
      if (!response.ok) throw new Error(`HTTP ${response.status}`);
      return await response.text();
    } catch (error) {
      if (attempt >= MAX_ATTEMPTS) {
        throw new Error(`KASI request for ${labelOf(solarMonth)} failed after ${MAX_ATTEMPTS} attempts`, { cause: error });
      }
      console.warn(`retrying ${labelOf(solarMonth)} (attempt ${attempt} failed: ${String(error)})`);
      await delay(RETRY_BASE_DELAY_MILLISECONDS * 2 ** (attempt - 1));
    }
  }
}

// Constraint: solDay를 생략하면 한 달 전체가 온다는 가정에 기대므로, 일부만 오면 표를 만들지 않고 멈춤
function assertWholeMonth(items: readonly KasiDayItem[], solarMonth: SolarMonth): void {
  const expectedDays = daysInGregorianMonth(solarMonth.year, solarMonth.month);
  if (items.length !== expectedDays) {
    throw new Error(
      `KASI returned ${items.length} days for ${labelOf(solarMonth)}; expected ${expectedDays}. solDay를 생략했을 때 한 달 전체를 돌려주지 않는 것으로 보임`,
    );
  }
}

async function writeDataFile(items: readonly KasiDayItem[], lastCollectedMonth: SolarMonth): Promise<void> {
  const monthStarts = extractMonthStarts(items);
  const lastDay = daysInGregorianMonth(lastCollectedMonth.year, lastCollectedMonth.month);
  const dataFile: KasiDataFile = {
    source: SOURCE,
    collectedAt: new Date().toISOString().slice(0, 10),
    solarRange: {
      from: toIsoDate({ ...FIRST_SOLAR_MONTH, day: 1 }),
      to: toIsoDate({ ...lastCollectedMonth, day: lastDay }),
    },
    monthStarts,
  };
  await mkdir(path.dirname(outputPath), { recursive: true });
  await writeFile(outputPath, `${JSON.stringify(dataFile, null, 2)}\n`);
  console.info(`wrote ${monthStarts.length} lunar month starts (${dataFile.solarRange.from} ~ ${dataFile.solarRange.to})`);
}

function labelOf(solarMonth: SolarMonth): string {
  return `${solarMonth.year}-${String(solarMonth.month).padStart(2, '0')}`;
}

try {
  await collectKasiData();
} catch (error) {
  console.error(error);
  process.exitCode = 1;
}

interface MonthSpec {
  readonly lunarYear: number;
  readonly lunarMonth: number;
  readonly isLeapMonth?: boolean;
  readonly days: number;
}

function monthStartsFrom(firstSolarStart: string, specs: readonly MonthSpec[]): KasiMonthStart[] {
  let cursor = epochDayFromCivil(
    Number(firstSolarStart.slice(0, 4)),
    Number(firstSolarStart.slice(5, 7)),
    Number(firstSolarStart.slice(8, 10)),
  );
  return specs.map((spec) => {
    const start = { ...spec, isLeapMonth: spec.isLeapMonth ?? false, solarStart: toIsoDate(civilFromEpochDay(cursor)) };
    cursor = (cursor + spec.days) as EpochDay;
    return start;
  });
}

function fullYear(lunarYear: number, leapMonth = 0): MonthSpec[] {
  const months: MonthSpec[] = [];
  for (let month = 1; month <= 12; month += 1) {
    months.push({ lunarYear, lunarMonth: month, days: month % 2 === 0 ? 29 : 30 });
    if (month === leapMonth) months.push({ lunarYear, lunarMonth: month, isLeapMonth: true, days: 29 });
  }
  return months;
}

import type { EpochDay } from '../../src/epoch-day';
import { type DangiYearRecord, isTruncated, monthCodesOf } from '../../src/dangi/year-record';
import { toMonthCode } from '../../src/month-code';
import { isoDateToEpochDay } from './iso-date';
import type { KasiMonthStart } from './kasi-types';

export const DANGI_FIRST_YEAR = 1900;

export function buildYearRecords(monthStarts: readonly KasiMonthStart[], firstYear: number): DangiYearRecord[] {
  const monthsByYear = groupByLunarYear(monthStarts.filter((start) => start.lunarYear >= firstYear));
  const years = [...monthsByYear.keys()];
  assertConsecutiveYears(years, firstYear);
  return years.map((year, index) => toYearRecord(year, monthsByYear.get(year) ?? [], index === years.length - 1));
}

export function lastEpochDayOf(monthStarts: readonly KasiMonthStart[]): number {
  const lastMonth = monthStarts.at(-1);
  if (!lastMonth) throw new Error('no lunar months to measure');
  return isoDateToEpochDay(lastMonth.solarStart) + lastMonth.days - 1;
}

function groupByLunarYear(monthStarts: readonly KasiMonthStart[]): Map<number, KasiMonthStart[]> {
  const monthsByYear = new Map<number, KasiMonthStart[]>();
  for (const start of monthStarts) monthsByYear.set(start.lunarYear, [...(monthsByYear.get(start.lunarYear) ?? []), start]);
  return monthsByYear;
}

function assertConsecutiveYears(years: readonly number[], firstYear: number): void {
  years.forEach((year, index) => {
    if (year !== firstYear + index) throw new Error(`expected lunar year ${firstYear + index}, found ${year}`);
  });
}

function toYearRecord(year: number, months: readonly KasiMonthStart[], isLastYear: boolean): DangiYearRecord {
  const firstMonth = months[0];
  if (!firstMonth || firstMonth.lunarMonth !== 1 || firstMonth.isLeapMonth) {
    throw new Error(`lunar year ${year} does not start with month 1`);
  }
  const leapMonths = months.filter((month) => month.isLeapMonth);
  if (leapMonths.length > 1) throw new Error(`lunar year ${year} has ${leapMonths.length} leap months`);
  const record: DangiYearRecord = {
    year,
    newYearEpochDay: isoDateToEpochDay(firstMonth.solarStart) as EpochDay,
    leapMonth: leapMonths[0]?.lunarMonth ?? 0,
    monthLengths: months.map((month) => month.days),
  };
  assertMonthOrder(record, months);
  if (!isLastYear && isTruncated(record)) throw new Error(`lunar year ${year} has only ${months.length} months`);
  return record;
}

function assertMonthOrder(record: DangiYearRecord, months: readonly KasiMonthStart[]): void {
  const actualCodes = months.map((month) => toMonthCode(month.lunarMonth, month.isLeapMonth));
  const expectedCodes = monthCodesOf(record);
  if (actualCodes.join() !== expectedCodes.join()) {
    throw new Error(`lunar year ${record.year} months are out of order: ${actualCodes.join(',')}`);
  }
}

import type { CalendarSystem, DateFields, SupportedRange } from '../calendar-system';
import type { EpochDay } from '../epoch-day';
import { LunisolarPickerError } from '../errors';
import type { MonthCode } from '../month-code';
import { type Result, err, ok } from '../result';
import type { ValidationReason } from '../validation-reason';
import { decodeDangiYear } from './table-codec';
import { type DangiYearRecord, isTruncated, monthCodesOf } from './year-record';

export interface DangiTable {
  readonly firstYear: number;
  readonly yearTable: readonly number[];
  readonly lastEpochDay: EpochDay;
}

export function createDangiCalendar(table: DangiTable): CalendarSystem {
  const records = table.yearTable.map((encoded, index) => decodeDangiYear(table.firstYear + index, encoded));
  const firstRecord = records[0];
  if (!firstRecord) throw new LunisolarPickerError('dangi table is empty');
  const lastYear = table.firstYear + records.length - 1;
  const supportedRange: SupportedRange = { min: firstRecord.newYearEpochDay, max: table.lastEpochDay };

  function findRecord(year: number): DangiYearRecord | undefined {
    return Number.isInteger(year) ? records[year - table.firstYear] : undefined;
  }

  function requireRecord(year: number): DangiYearRecord {
    const record = findRecord(year);
    if (!record) throw new LunisolarPickerError(`dangi supports lunar years ${table.firstYear}-${lastYear}, received ${year}`);
    return record;
  }

  return {
    id: 'dangi',
    supportedRange,
    monthsInYear: (year) => monthCodesOf(requireRecord(year)),
    daysInMonth(year, monthCode) {
      const record = requireRecord(year);
      const days = record.monthLengths[monthCodesOf(record).indexOf(monthCode)];
      if (days === undefined) throw new LunisolarPickerError(`lunar year ${year} has no month ${monthCode}`);
      return days;
    },
    toEpochDay(fields) {
      const record = findRecord(fields.year);
      if (!record) return err('outside-calendar-range');
      return epochDayInRecord(record, fields);
    },
    fromEpochDay(epochDay) {
      if (epochDay < supportedRange.min || epochDay > supportedRange.max) return err('outside-calendar-range');
      return ok(fieldsInRecord(findRecordContaining(records, epochDay), epochDay));
    },
  };
}

function epochDayInRecord(record: DangiYearRecord, { monthCode, day }: DateFields): Result<EpochDay, ValidationReason> {
  const monthIndex = monthCodesOf(record).indexOf(monthCode);
  // Constraint: 데이터가 끝난 마지막 해의 뒤쪽 달은 실제로 있을 수 있으므로 '없는 날짜'가 아니라 '범위 밖'으로 알림
  if (monthIndex === -1) return err(isTruncated(record) ? 'outside-calendar-range' : 'invalid-date');
  const days = record.monthLengths[monthIndex] ?? 0;
  if (!Number.isInteger(day) || day < 1 || day > days) return err('invalid-date');
  const daysBeforeMonth = record.monthLengths.slice(0, monthIndex).reduce((total, length) => total + length, 0);
  return ok((record.newYearEpochDay + daysBeforeMonth + day - 1) as EpochDay);
}

function findRecordContaining(records: readonly DangiYearRecord[], epochDay: EpochDay): DangiYearRecord {
  let lowIndex = 0;
  let highIndex = records.length - 1;
  while (lowIndex < highIndex) {
    const middleIndex = Math.ceil((lowIndex + highIndex) / 2);
    const middleRecord = records[middleIndex];
    if (middleRecord && middleRecord.newYearEpochDay <= epochDay) lowIndex = middleIndex;
    else highIndex = middleIndex - 1;
  }
  const record = records[lowIndex];
  if (!record) throw new LunisolarPickerError(`no lunar year contains epoch day ${epochDay}`);
  return record;
}

function fieldsInRecord(record: DangiYearRecord, epochDay: EpochDay): DateFields {
  const monthCodes = monthCodesOf(record);
  let remainingDays = epochDay - record.newYearEpochDay;
  for (const [index, days] of record.monthLengths.entries()) {
    if (remainingDays < days) return { year: record.year, monthCode: monthCodes[index] as MonthCode, day: remainingDays + 1 };
    remainingDays -= days;
  }
  throw new LunisolarPickerError(`epoch day ${epochDay} is past the known months of lunar year ${record.year}`);
}

import { gzipSync } from 'node:zlib';

interface SizeBudget {
  readonly label: string;
  readonly entry: string;
  readonly maxGzipBytes: number;
}

// Constraint: 스펙 11장 예산. 소비자가 minify하는 조건으로 잼. 넘으면 예산을 올리지 말고 원인을 보고
const SIZE_BUDGETS: readonly SizeBudget[] = [
  { label: '@lunisolar-picker/calendar', entry: 'packages/calendar/dist/index.js', maxGzipBytes: 2048 },
  { label: '@lunisolar-picker/calendar/dangi', entry: 'packages/calendar/dist/dangi.js', maxGzipBytes: 3072 },
  { label: 'dangi table only', entry: 'packages/calendar/src/dangi/dangi-table.generated.ts', maxGzipBytes: 1024 },
];

async function measureGzipBytes(entry: string): Promise<number> {
  const result = await build({
    entryPoints: [entry],
    bundle: true,
    minify: true,
    format: 'esm',
    platform: 'neutral',
    write: false,
  });
  const output = result.outputFiles[0];
  if (!output) throw new Error(`esbuild produced no output for ${entry}`);
  return gzipSync(output.contents).byteLength;
}

async function checkBundleSizes(): Promise<void> {
  const overBudget: string[] = [];
  for (const budget of SIZE_BUDGETS) {
    const gzipBytes = await measureGzipBytes(budget.entry);
    console.info(`${budget.label}: ${gzipBytes} B gzip (budget ${budget.maxGzipBytes} B)`);
    if (gzipBytes > budget.maxGzipBytes) overBudget.push(budget.label);
  }
  if (overBudget.length > 0) throw new Error(`over size budget: ${overBudget.join(', ')}`);
}

try {
  await checkBundleSizes();
} catch (error) {
  console.error(error);
  process.exitCode = 1;
}

import { mkdir, writeFile } from 'node:fs/promises';
import path from 'node:path';
import { fileURLToPath } from 'node:url';
import { dangi } from '../src/dangi/index';
import { type EpochDay, civilFromEpochDay } from '../src/epoch-day';
import { toMonthCode } from '../src/month-code';
import { toIsoDate } from './kasi/iso-date';

interface IntlDifference {
  readonly solarDate: string;
  readonly kasi: string;
  readonly intl: string;
}

const MILLISECONDS_PER_DAY = 86_400_000;
const LEAP_MARKER = '윤';
const packageRoot = path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..');
const reportPath = path.join(packageRoot, '.cache/intl-dangi-diff.md');
const intlFormatter = new Intl.DateTimeFormat('ko-KR-u-ca-dangi', {
  year: 'numeric',
  month: 'numeric',
  day: 'numeric',
  timeZone: 'UTC',
});

function describeIntlDate(epochDay: EpochDay): string {
  const parts = intlFormatter.formatToParts(new Date(epochDay * MILLISECONDS_PER_DAY));
  const partOf = (type: string): string => parts.find((part) => part.type === type)?.value ?? '';
  const monthText = partOf('month');
  const monthCode = toMonthCode(Number(monthText.replace(/\D/g, '')), monthText.includes(LEAP_MARKER));
  return `${partOf('relatedYear') || partOf('year')} ${monthCode} ${partOf('day')}`;
}

// Goal: 정보용 리포트. 브라우저마다 Intl이 KASI와 다른 날짜를 기록해 두고 빌드는 막지 않음 (스펙 5.3)
async function compareWithIntl(): Promise<void> {
  const differences: IntlDifference[] = [];
  for (let epochDay = dangi.supportedRange.min; epochDay <= dangi.supportedRange.max; epochDay = (epochDay + 1) as EpochDay) {
    const fields = dangi.fromEpochDay(epochDay);
    if (!fields.isOk) throw new Error(`dangi rejected a supported day ${epochDay}: ${fields.error}`);
    const kasi = `${fields.value.year} ${fields.value.monthCode} ${fields.value.day}`;
    const intl = describeIntlDate(epochDay);
    if (kasi !== intl) differences.push({ solarDate: toIsoDate(civilFromEpochDay(epochDay)), kasi, intl });
  }
  const rows = differences.map((difference) => `| ${difference.solarDate} | ${difference.kasi} | ${difference.intl} |`);
  await mkdir(path.dirname(reportPath), { recursive: true });
  await writeFile(reportPath, ['| 양력 | KASI | Intl |', '|---|---|---|', ...rows, ''].join('\n'));
  console.info(`Node ${process.version}: ${differences.length} days differ from Intl dangi. report: ${reportPath}`);
}

try {
  await compareWithIntl();
