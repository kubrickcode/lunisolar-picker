# M2: core 패키지 (제약·격자·상태·제스처·로케일) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 프레임워크와 무관한 `@lunisolar-picker/core`를 만든다. 범위는 제약 해석·검증, 월 격자, navigation/selection/field/column 순수 리듀서, 휠 관성·가장자리 머묾 계산, ko/en/ja 로케일 데이터다.

**Architecture:**
- 모든 상태는 `(state, event, context) → state` 순수 리듀서이고, `createStore`가 그 위에 `subscribe`/`getSnapshot`/`send`를 씌운다.
- 역법은 `@lunisolar-picker/calendar`의 `CalendarSystem`으로만 다룬다. 날짜는 내부에서 `EpochDay`로 계산한다.
- core는 DOM을 모른다: `lib`에 DOM이 없고, `console`도 쓰지 않는다. 바인딩이 알아야 할 문제는 반환 값(`ignoredInputs` 등)으로 알린다.

**Tech Stack:** M1과 같다(TypeScript 6.0.3, tsdown 0.23.1, vitest 5.0.4, fast-check 4.10.2, Biome 2.5.15, dependency-cruiser 18.6.0). 새 런타임 의존성은 `@lunisolar-picker/calendar`(`workspace:*`) 하나다.

**Spec:** `docs/superpowers/specs/2026-10-14-lunisolar-picker-design.md`. 특히 다음 장을 본다.
- 3장 아키텍처
- 5.4 없는 날짜 처리
- 6장 코어
- 9장 다국어
- 10장 키보드
- 11장 테스트

**계약:** `docs/superpowers/plans/2026-10-14-v1-interface-contract.md` §2. 이 계획에서 계약과 달라진 부분은 아래 "계약과 다른 점"에 모았다.

**전제:** M1이 끝나 있다. `@lunisolar-picker/calendar`와 `@lunisolar-picker/calendar/dangi`가 KASI 실데이터로 동작해야 한다.

## 계약과 다른 점 (정합성 조정에서 계약 문서에 반영 완료)

1. **selection 상태의 확정 값과 임시 값이 역법을 함께 들고 다닌다.**
   - 단일 선택: `SelectedDay { epochDay, calendarId }`
   - 범위 선택: `SelectedRange { range, calendarId }`
   - 이유: 계약의 `committed: EpochDay` + 상태 하나에 `entryCalendarId` 하나 구조로는 확정 값과 임시 값의 입력 역법이 다를 때 취소해도 역법이 원래대로 돌아오지 않는다.
   - `value.sync` 이벤트는 `selected` 하나만 받는다.
2. **`EpochRange`를 `types.ts`로 옮긴다.** constraints와 selection이 서로를 import하지 않게 하려는 것이다.
3. **`PickerContext.constraints`는 양력 기준으로 해석한 제약이다.**
   - 표시 역법의 지원 범위는 리듀서가 `boundsFor(calendar, constraints)`로 겹쳐 계산한다.
   - 이유: 표시 역법은 navigation 상태에 있으므로, 바인딩이 그 역법에 맞춰 컨텍스트를 만들면 상태와 컨텍스트가 서로를 참조하는 순환이 생긴다.
4. **`ResolvedConstraints`에 필드 두 개가 추가된다.**
   - `supportedRange`: 이 값이 있어야 `'outside-calendar-range'`와 `'before-min'`/`'after-max'`를 구분할 수 있다.
   - `ignoredInputs`: core는 콘솔을 쓰지 않으므로, 해석에 실패한 `min`/`max`를 바인딩이 경고할 수 있게 넘긴다.
5. **`resolveConstraints`에 세 번째 인자 `knownCalendars`가 추가된다.** `min: '…[u-ca=dangi]'`처럼 역법 표기가 붙은 값을 해석하려면 필요하다.
6. **`MonthGridCell`에 `isOutsideSupportedRange`가 추가된다.** 6주 격자의 앞뒤 칸은 표시 역법의 지원 범위 밖일 수 있다(예: 음력 1900년 1월 앞의 칸).
7. **`listYearPage`의 두 번째 인자는 페이지 시작 연도다.** 시작 연도는 `yearPageStartOf(year, pageSize)`로 구한다.
8. **`createDateFieldState`와 `createTimeFieldState`의 인자가 바뀐다.**
   - `createDateFieldState(context, { selected, entryCalendarId })`: 값이 비어 있어도 입력 역법을 알아야 하기 때문이다. 같은 이유로 date field의 `value.sync`도 `{ selected, entryCalendarId }`를 받는다.
   - `createTimeFieldState(initial, timeContext)`: 시 칸의 최댓값이 `24:00` 허용 여부에 따라 달라지기 때문이다.
9. **`LocaleData.field`에 `leapMonthPrefix`(`'윤'`, `'L'`, `'閏'`)가 추가된다.** 필드 표시 문자열(`1990. 윤05. 01`)에 필요하다.
10. **`constrainDateFields`, `boundsFor`, `clampEpochDay`, `fieldsOf`, `firstEpochDayOfMonth`, `supportedYearRange`를 `grid/calendar-math.ts`에서 공개한다.** navigation과 휠 모델이 함께 쓰는 날짜 계산이다.

## Global Constraints

- M1 계획의 Global Constraints 전부(정확한 버전, ESM 전용, 이름·주석·테스트·커밋 규칙, `ALLOW_COMMIT=1`)
- core 런타임 의존성은 `@lunisolar-picker/calendar` 하나뿐이다. `package.json`에는 `"workspace:*"`로 적는다(배포 시 pnpm이 정확한 버전으로 바꾼다).
- calendar는 공개 진입점(`@lunisolar-picker/calendar`, `@lunisolar-picker/calendar/dangi`)으로만 import한다. calendar의 `src/` 내부 파일을 직접 import하지 않는다.
- core의 `tsconfig` `lib`는 `["ES2022"]`이고 DOM이 없다. `window`, `document`, `console`, `setTimeout`을 쓰지 않는다. 시각이 필요한 곳은 `nowMs` 인자로 받는다.
- 리듀서는 순수 함수다. 아무것도 바뀌지 않는 이벤트에는 **같은 state 참조**를 돌려준다. `createStore`는 이것으로 알림 여부를 정한다.
- 역법 종류(`'dangi'`)에 따라 분기하지 않는다. 역법마다 다른 동작은 모두 `CalendarSystem` 메서드로 얻는다. 양력 자체를 가리킬 때만 `gregory.id`와 비교할 수 있다.
- 일수 제한(`minDays`, `maxDays`)은 **양 끝을 포함한 일수**다. 10월 13일~15일은 3일이다.

## Review Focus

1. **최대 기간 경계**: `maxDays: 3`에서 3일 범위는 유효하고 4일 범위는 `'range-too-long'`이어야 한다. `'block'` 모드에서는 anchor부터 3일째까지 고를 수 있고 4일째는 무시해야 한다. Task 4·7에서 확인한다.
2. **월 이동과 말일**: 1월 31일에 포커스를 둔 채 한 달 뒤로 가면 2월 28일이어야 한다. 3월 3일처럼 다음 달로 넘어가면 안 된다. Task 6에서 확인한다.
3. **윤달이 사라지는 해로 이동**: 음력 2025년 윤6월에서 1년 뒤로 가면 2026년 6월이어야 한다. 데이터가 끝난 마지막 해에서 없는 달로 가면 가장 가까운 있는 달이어야 한다. Task 5·6에서 확인한다.
4. **붙여넣기 형식이 섞인 경우**: en 로케일(월/일/연)에 ISO `1990-03-15`를 붙여넣거나, `1990년 3월 15일`처럼 숫자 아닌 글자가 섞여 있어도 올바른 날짜가 되어야 한다. 해석할 수 없는 문자열이면 상태가 바뀌지 않아야 한다. Task 8에서 확인한다.
5. **드래그 중 막힌 날짜 위를 지날 때**: 비활성 날짜나 `'block'` 범위 밖 날짜에 들어가면 미리보기 끝점은 직전의 유효한 날짜에 머물러야 한다. 손을 떼면 그 유효한 날짜로 범위가 완성되어야 한다. Task 7에서 확인한다.

```markdown
# 순수 TS 코어 + 층 구조 React API + calendar 패키지 분리

## 맥락

- 이 라이브러리는 어떤 프로젝트에서도 쓸 수 있는 범용성을 목표로 한다. 첫 바인딩은 React이고, Vue·Svelte는 나중에 붙인다.
- 교체 대상인 web-console과 back-office는 react-day-picker(설정형 단일 컴포넌트)를 쓰고 있다. 그런데 열려 있는 슬롯만으로는 부족해서 Nav, DayButton, 팝오버, 드래그 선택, 범위 정책을 결국 직접 다시 짰다.
- 서버에서 음력↔양력 변환만 필요한 소비자가 있다. KASI 데이터를 정정하면 picker와 따로 릴리스해야 한다.

## 결정

- 패키지는 `calendar ← core ← react` 한 방향으로만 의존한다. `theme`는 CSS만 담고 `data-*` 계약에만 의존한다.
- `calendar`: 날짜 타입, 문자열 값, 역법 인터페이스, 양력, `./dangi`. 런타임 의존성은 0이다.
- `core`: 순수 리듀서와 `createStore`로 만든 상태, 제약, 격자, 제스처 계산, 로케일 데이터. DOM과 React를 모른다.
- `react`: 훅 → compound 부품(`Calendar.*` 등) → 완성형(`/pickers`)의 세 층으로 만든다. 완성형은 부품의 공개 API만 쓴다.

## 검토한 대안

- **React 전용**: 가장 빠르게 만들 수 있지만 범용성 목표를 채우지 못한다.
- **Web Components**: Shadow DOM 때문에 Tailwind 유틸리티로 덮어쓸 수 없고, ARIA 참조도 경계를 넘지 못한다. Astro와 Cloudflare의 SSR과도 잘 맞지 않는다.
- **훅만 제공 (React Aria 방식)**: 바로 쓸 수 있는 컴포넌트가 없어서, 앱마다 같은 조립 코드를 반복해서 짜야 한다.
- **설정형 단일 컴포넌트 (rdp 방식)**: 교체 대상 앱들이 이 구조의 한계 때문에 대부분을 다시 짰다.
- **역법을 core 안에 두기**: 나중에 분리하면 import 경로가 바뀌어 하위 호환이 깨진다.

## 결과

- 상태 로직을 프레임워크 없이 단위 테스트할 수 있다. 다른 바인딩은 react에 해당하는 층만 새로 만들면 된다.
- 공개 API가 넓어져서 안정성 등급을 따로 관리해야 한다. 훅, 부품 이름, `data-*`는 stable이고, 완성형은 조합 예시로 본다.
- 처음 설계 비용과 문서 분량이 늘어난다.
```

```markdown
# 한국 음력은 내장 KASI 표로 계산하고 1900~2050년만 지원

## 맥락

- 브라우저 `Intl.DateTimeFormat('…-u-ca-dangi')`은 엔진(ICU4C, ICU4X, AppleICU)마다 윤달 연도와 월 길이가 다른 사례가 보고되어 있다. 서버(V8)와 iOS(AppleICU)가 다르게 그리면 hydration mismatch가 난다.
- `Temporal`의 dangi 역법은 iOS Safari에서 아직 지원되지 않는다. 그런데 카카오톡 인앱 트래픽 대부분이 iOS다.
- 한국천문연구원(KASI)은 공식 음양력 데이터를 1900~2050년 범위로 제공한다.

## 결정

- KASI OpenAPI 원본을 한 번 수집해 레포에 커밋한다. 그 원본에서 연 단위 정수 표(설날 위치, 달 대소, 윤달, 알려진 달 수)를 생성해 `@lunisolar-picker/calendar/dangi`에 내장한다.
- 지원 범위는 음력 1900년 1월 1일부터 KASI 데이터의 마지막 날까지다. 범위 밖은 `'outside-calendar-range'`로 알리고, 범위 밖 날짜를 조용히 계산하지 않는다.
- 브라우저 Intl과의 차이는 정보용 리포트로만 남긴다.

## 검토한 대안

- **Intl dangi 사용**: 용량은 0KB지만 결과가 엔진마다 달라 결정적이지 않다.
- **Temporal 사용**: iOS에서 지원되지 않는다. polyfill은 크고, 같은 ICU 편차를 물려받을 가능성이 있다.
- **천문 계산으로 2051년 이후까지 확장**: 공식 발표값이 아니다. 사용자가 범위를 1900~2050으로 정했다.
- **중국 농력 동시 지원**: v1에서는 빼고, 역법 인터페이스를 공개해 두어 나중에 구현체만 추가하게 한다.

## 결과

- 모든 환경에서 같은 결과가 나오고, KASI 정답 데이터로 검증할 수 있다.
- 음력 표는 gzip 1KB 안팎이고, 음력을 쓰지 않는 번들에서는 빠진다.
- 2050년 이후 음력은 다룰 수 없다. KASI가 범위를 넓히면 수집과 생성을 다시 돌린다.
```

```markdown
# 공개 값은 정규 문자열, 내부 계산은 epoch day

## 맥락

- web-console과 back-office는 날짜를 이미 `YYYY-MM-DD`, 시간을 `HH:mm` 문자열로 저장한다. URL 쿼리, react-hook-form, Next 서버 컴포넌트 props에도 이 문자열을 그대로 넘긴다.
- back-office는 `toISOString()`으로 UTC "오늘"을 계산한다. 그래서 KST 오전 0~9시에는 기본값이 하루 전 날짜가 된다. web-console은 로컬 날짜에 `Z`만 붙인 가짜 UTC 값을 저장한다. 두 버그 모두 날짜를 `Date` 객체로 다뤄서 생겼다.
- 음력으로 입력한 날짜는 "음력으로 입력했다"는 정보를 잃으면 안 된다.

## 결정

- 공개 값은 문자열이다: 날짜 `YYYY-MM-DD`, 음력 입력 날짜 `YYYY-MM-DD[u-ca=dangi]`, 시간 `HH:mm`, 월 `YYYY-MM`. 모두 Temporal 문자열 형식과 호환된다.
- 출력 타입은 `DateString` 같은 브랜드 타입이다. 입력은 경계에서 한 번만 엄격하게 해석한다. 정규 형식은 하나뿐이므로 같은 날짜·같은 역법이면 `===`로 같다.
- 내부 계산은 epoch day(1970-01-01부터의 일수) 정수로 한다. 화면에 보여 주는 역법과 값의 역법을 분리한다.

## 검토한 대안

- **Temporal 같은 객체를 공개 값으로**: 필드에 바로 접근할 수 있다. 하지만 비교, 직렬화, URL, 폼 연동에서 매번 변환해야 한다.
- **`Date` 객체**: 타임존 버그의 원인이다.

## 결과

- 비교, 직렬화, 폼 연동이 단순해진다. 나중에 `Temporal.PlainDate.from()`으로 바로 읽을 수 있다.
- 필드가 필요하면 `parseDate()`를 한 번 거쳐야 한다.
- 같은 날을 서로 다른 역법으로 입력하면 문자열이 다르다. 같은 날인지는 `isSameDay()`로 비교한다.
```

```ts
import {
  type CalendarId,
  type EpochDay,
  LunisolarPickerError,
  type MonthCode,
  VALIDATION_REASONS,
  type ValidationReason,
} from '@lunisolar-picker/calendar';

export type Weekday = 0 | 1 | 2 | 3 | 4 | 5 | 6;
export type CommitMode = 'immediate' | 'confirm';
export type DateSegmentKind = 'year' | 'month' | 'day';
export type TimeSegmentKind = 'hour' | 'minute';

export interface Validity {
  readonly isValid: boolean;
  readonly reasons: readonly ValidationReason[];
}

export interface VisibleMonth {
  readonly year: number;
  readonly monthCode: MonthCode;
}

export interface SecondaryDateLabel {
  readonly calendarId: CalendarId;
  readonly monthCode: MonthCode;
  readonly day: number;
  readonly isLeapMonth: boolean;
  readonly isFirstDayOfMonth: boolean;
}

export interface EpochRange {
  readonly start: EpochDay;
  readonly end: EpochDay | null;
}

export const VALID: Validity = { isValid: true, reasons: [] };

const DAYS_PER_WEEK = 7;

// Goal: 같은 이유 묶음이면 순서까지 같게 해서 테스트·화면 문구가 결정적이 되도록 함
export function invalidBecause(reasons: Iterable<ValidationReason>): Validity {
  const reasonSet = new Set(reasons);
  if (reasonSet.size === 0) return VALID;
  return { isValid: false, reasons: VALIDATION_REASONS.filter((reason) => reasonSet.has(reason)) };
}

export function toWeekday(value: number): Weekday {
  if (!Number.isInteger(value) || value < 0 || value >= DAYS_PER_WEEK) {
    throw new LunisolarPickerError(`weekday must be an integer from 0 to 6, received ${value}`);
  }
  return value as Weekday;
}
```

`packages/core/src/create-store.ts`:
```ts
export type Reducer<State, Event, Context> = (state: State, event: Event, context: Context) => State;

export interface Store<State, Event> {
  getSnapshot(): State;
  subscribe(listener: () => void): () => void;
  send(event: Event): void;
}

export interface CreateStoreOptions<State, Event, Context> {
  readonly initialState: State;
  readonly reducer: Reducer<State, Event, Context>;
  readonly readContext: () => Context;
}

// Goal: 바인딩이 최신 prop을 readContext로 넘기므로 prop이 바뀌어도 store를 다시 만들지 않음 (스펙 3.3)
export function createStore<State, Event, Context>(
  options: CreateStoreOptions<State, Event, Context>,
): Store<State, Event> {
  let state = options.initialState;
  const listeners = new Set<() => void>();
  return {
    getSnapshot: () => state,
    subscribe(listener) {
      listeners.add(listener);
      return () => {
        listeners.delete(listener);
      };
    },
    send(event) {
      const nextState = options.reducer(state, event, options.readContext());
      if (Object.is(nextState, state)) return;
      state = nextState;
      for (const listener of [...listeners]) listener();
    },
  };
}
```

```ts
export function defineLocale(locale: LocaleData): LocaleData {
  const problems = [
    describeLengthProblem('months.long', locale.months.long, MONTHS_PER_YEAR),
    describeLengthProblem('months.short', locale.months.short, MONTHS_PER_YEAR),
    describeLengthProblem('weekdays.narrow', locale.weekdays.narrow, DAYS_PER_WEEK),
    describeLengthProblem('weekdays.short', locale.weekdays.short, DAYS_PER_WEEK),
    describeLengthProblem('weekdays.long', locale.weekdays.long, DAYS_PER_WEEK),
    isSegmentPermutation(locale.field.order) ? '' : 'field.order must contain year, month and day exactly once',
    ...VALIDATION_REASONS.filter((reason) => locale.labels.validation[reason] === '').map(
      (reason) => `labels.validation.${reason} is empty`,
    ),
  ].filter((problem) => problem !== '');
  if (problems.length > 0) throw new LunisolarPickerError(`invalid locale "${locale.id}": ${problems.join('; ')}`);
  return locale;
}

function describeLengthProblem(path: string, values: readonly string[], expectedLength: number): string {
  return values.length === expectedLength ? '' : `${path} must have ${expectedLength} entries, found ${values.length}`;
}

function isSegmentPermutation(order: readonly DateSegmentKind[]): boolean {
  return order.length === DATE_SEGMENT_KINDS.length && DATE_SEGMENT_KINDS.every((kind) => order.includes(kind));
}
```

```ts
import { type CalendarSystem, type EpochDay, LunisolarPickerError, parseMonthCode } from '@lunisolar-picker/calendar';
import { padDigits } from '../format-digits';
import type { DateSegmentKind } from '../types';
import type { LocaleData } from './locale-data';

const YEAR_DIGITS = 4;
const MONTH_DAY_DIGITS = 2;

export function formatDateForField(
  epochDay: EpochDay,
  calendar: CalendarSystem,
  locale: LocaleData,
  separator: string = locale.field.separator,
): string {
  const fields = calendar.fromEpochDay(epochDay);
  if (!fields.isOk) {
    throw new LunisolarPickerError(`cannot display epoch day ${epochDay} in ${calendar.id}: ${fields.error}`);
  }
  const { month, isLeapMonth } = parseMonthCode(fields.value.monthCode);
  const textByKind: Readonly<Record<DateSegmentKind, string>> = {
    year: padDigits(fields.value.year, YEAR_DIGITS),
    month: `${isLeapMonth ? locale.field.leapMonthPrefix : ''}${padDigits(month, MONTH_DAY_DIGITS)}`,
    day: padDigits(fields.value.day, MONTH_DAY_DIGITS),
  };
  return locale.field.order.map((kind) => textByKind[kind]).join(separator);
}
```

```ts
import {
  type CalendarSystem,
  type DateString,
  type EpochDay,
  LunisolarPickerError,
  type SupportedRange,
  type ValidationReason,
  formatDate,
  gregory,
  parseDate,
} from '@lunisolar-picker/calendar';

export type RangeLimitMode = 'block' | 'flag';

export interface DateConstraints {
  readonly min?: string;
  readonly max?: string;
  readonly isDateDisabled?: (date: DateString) => boolean;
}

export interface RangeConstraints extends DateConstraints {
  readonly minDays?: number;
  readonly maxDays?: number;
  readonly limitMode?: RangeLimitMode;
  readonly isOpenEndAllowed?: boolean;
}

export interface IgnoredConstraintInput {
  readonly field: 'min' | 'max';
  readonly input: string;
  readonly reason: ValidationReason;
}

export interface ResolvedConstraints {
  readonly minEpochDay: EpochDay;
  readonly maxEpochDay: EpochDay;
  readonly supportedRange: SupportedRange;
  readonly isEpochDayDisabled: (epochDay: EpochDay) => boolean;
  readonly minDays: number | null;
  readonly maxDays: number | null;
  readonly limitMode: RangeLimitMode;
  readonly isOpenEndAllowed: boolean;
  readonly ignoredInputs: readonly IgnoredConstraintInput[];
}

const DEFAULT_LIMIT_MODE: RangeLimitMode = 'block';

export function resolveConstraints(
  constraints: RangeConstraints,
  displayCalendar: CalendarSystem = gregory,
  knownCalendars: readonly CalendarSystem[] = [displayCalendar],
): ResolvedConstraints {
  assertDayCounts(constraints);
  const ignoredInputs: IgnoredConstraintInput[] = [];
  const minBound = readBound('min', constraints.min, knownCalendars, ignoredInputs);
  const maxBound = readBound('max', constraints.max, knownCalendars, ignoredInputs);
  const supportedRange: SupportedRange = {
    min: Math.max(displayCalendar.supportedRange.min, gregory.supportedRange.min) as EpochDay,
    max: Math.min(displayCalendar.supportedRange.max, gregory.supportedRange.max) as EpochDay,
  };
  return {
    minEpochDay: (minBound === null ? supportedRange.min : Math.max(minBound, supportedRange.min)) as EpochDay,
    maxEpochDay: (maxBound === null ? supportedRange.max : Math.min(maxBound, supportedRange.max)) as EpochDay,
    supportedRange,
    isEpochDayDisabled: toEpochDayPredicate(constraints.isDateDisabled),
    minDays: constraints.minDays ?? null,
    maxDays: constraints.maxDays ?? null,
    limitMode: constraints.limitMode ?? DEFAULT_LIMIT_MODE,
    isOpenEndAllowed: constraints.isOpenEndAllowed ?? false,
    ignoredInputs,
  };
}

// Constraint: core는 콘솔을 쓰지 않으므로 해석에 실패한 경계는 버리고 ignoredInputs로 바인딩에 넘김
function readBound(
  field: 'min' | 'max',
  input: string | undefined,
  knownCalendars: readonly CalendarSystem[],
  ignoredInputs: IgnoredConstraintInput[],
): EpochDay | null {
  if (input === undefined) return null;
  const parsed = parseDate(input, { calendars: knownCalendars });
  if (parsed.isOk) return parsed.value.epochDay;
  ignoredInputs.push({ field, input, reason: parsed.error });
  return null;
}

function assertDayCounts(constraints: RangeConstraints): void {
  for (const [name, value] of [['minDays', constraints.minDays], ['maxDays', constraints.maxDays]] as const) {
    if (value !== undefined && (!Number.isInteger(value) || value < 1)) {
      throw new LunisolarPickerError(`${name} must be a positive integer, received ${value}`);
    }
  }
  const { minDays, maxDays } = constraints;
  if (minDays !== undefined && maxDays !== undefined && minDays > maxDays) {
    throw new LunisolarPickerError(`minDays (${minDays}) cannot exceed maxDays (${maxDays})`);
  }
}

function toEpochDayPredicate(isDateDisabled: ((date: DateString) => boolean) | undefined): (epochDay: EpochDay) => boolean {
  if (!isDateDisabled) return () => false;
  return (epochDay) => {
    const date = formatDate(epochDay);
    return date.isOk && isDateDisabled(date.value);
  };
}
```

```ts
import type { EpochDay, ValidationReason } from '@lunisolar-picker/calendar';
import { type EpochRange, type Validity, invalidBecause } from '../types';
import type { ResolvedConstraints } from './resolve-constraints';

export function validateEpochDay(epochDay: EpochDay, constraints: ResolvedConstraints): Validity {
  return invalidBecause(dayReasons(epochDay, constraints));
}

export function validateEpochRange(range: EpochRange, constraints: ResolvedConstraints): Validity {
  const reasons = dayReasons(range.start, constraints);
  if (range.end === null) {
    if (!constraints.isOpenEndAllowed) reasons.push('incomplete');
    return invalidBecause(reasons);
  }
  reasons.push(...dayReasons(range.end, constraints));
  const dayCount = range.end - range.start + 1;
  if (constraints.minDays !== null && dayCount < constraints.minDays) reasons.push('range-too-short');
  if (constraints.maxDays !== null && dayCount > constraints.maxDays) reasons.push('range-too-long');
  if (hasDisabledDayBetween(range.start, range.end, constraints)) reasons.push('range-includes-disabled');
  return invalidBecause(reasons);
}

// Goal: 'block' 모드에서 anchor 기준으로 범위 길이 제한을 어기게 될 날은 선택 중에 고를 수 없게 함 (스펙 2.2)
export function isEpochDayInBlockedRange(anchor: EpochDay, candidate: EpochDay, constraints: ResolvedConstraints): boolean {
  if (constraints.limitMode !== 'block' || candidate === anchor) return false;
  const dayCount = Math.abs(candidate - anchor) + 1;
  const isTooLong = constraints.maxDays !== null && dayCount > constraints.maxDays;
  const isTooShort = constraints.minDays !== null && dayCount < constraints.minDays;
  return isTooLong || isTooShort;
}

function dayReasons(epochDay: EpochDay, constraints: ResolvedConstraints): ValidationReason[] {
  if (epochDay < constraints.supportedRange.min || epochDay > constraints.supportedRange.max) {
    return ['outside-calendar-range'];
  }
  if (epochDay < constraints.minEpochDay) return ['before-min'];
  if (epochDay > constraints.maxEpochDay) return ['after-max'];
  return constraints.isEpochDayDisabled(epochDay) ? ['disabled-date'] : [];
}

function hasDisabledDayBetween(start: EpochDay, end: EpochDay, constraints: ResolvedConstraints): boolean {
  for (let epochDay = start + 1; epochDay < end; epochDay += 1) {
    if (constraints.isEpochDayDisabled(epochDay as EpochDay)) return true;
  }
  return false;
}
```

```ts
import { type CalendarId, type CalendarSystem, type EpochDay, gregory, parseDate } from '@lunisolar-picker/calendar';
import { findCalendar } from '../context';
import { type Validity, invalidBecause } from '../types';
import { type DateConstraints, type RangeConstraints, resolveConstraints } from './resolve-constraints';
import { validateEpochDay, validateEpochRange } from './validate';

export interface ValidationOptions {
  readonly calendars?: readonly CalendarSystem[];
}

// Goal: 앱이 프리셋 버튼을 비활성화·강조할 때 picker 상태 없이 문자열만으로 같은 규칙을 쓰게 함 (스펙 2.2)
export function validateDate(value: string, constraints: DateConstraints = {}, options: ValidationOptions = {}): Validity {
  const knownCalendars = withGregorian(options.calendars);
  const parsed = parseDate(value, { calendars: knownCalendars });
  if (!parsed.isOk) return invalidBecause([parsed.error]);
  const resolved = resolveConstraints(constraints, findCalendar(knownCalendars, parsed.value.calendar), knownCalendars);
  return validateEpochDay(parsed.value.epochDay, resolved);
}

export function validateRange(
  range: { readonly start: string; readonly end: string | null },
  constraints: RangeConstraints = {},
  options: ValidationOptions = {},
): Validity {
  const knownCalendars = withGregorian(options.calendars);
  const start = parseDate(range.start, { calendars: knownCalendars });
  const end = range.end === null ? null : parseDate(range.end, { calendars: knownCalendars });
  if (!start.isOk) return invalidBecause([start.error]);
  if (end !== null && !end.isOk) return invalidBecause([end.error]);
  const displayCalendarId: CalendarId = start.value.calendar;
  const resolved = resolveConstraints(constraints, findCalendar(knownCalendars, displayCalendarId), knownCalendars);
  const endEpochDay: EpochDay | null = end === null ? null : end.value.epochDay;
  const isReversed = endEpochDay !== null && endEpochDay < start.value.epochDay;
  return validateEpochRange(
    isReversed ? { start: endEpochDay, end: start.value.epochDay } : { start: start.value.epochDay, end: endEpochDay },
    resolved,
  );
}

function withGregorian(calendars: readonly CalendarSystem[] | undefined): readonly CalendarSystem[] {
  const extraCalendars = (calendars ?? []).filter((calendar) => calendar.id !== gregory.id);
  return [gregory, ...extraCalendars];
}
```

```ts
import {
  type CalendarSystem,
  type DateFields,
  type EpochDay,
  LunisolarPickerError,
  type MonthCode,
  parseMonthCode,
  toMonthCode,
} from '@lunisolar-picker/calendar';
import type { ResolvedConstraints } from '../constraints/resolve-constraints';
import type { VisibleMonth } from '../types';

export interface CalendarBounds {
  readonly min: EpochDay;
  readonly max: EpochDay;
}

export function boundsFor(calendar: CalendarSystem, constraints: ResolvedConstraints): CalendarBounds {
  return {
    min: Math.max(constraints.minEpochDay, calendar.supportedRange.min) as EpochDay,
    max: Math.min(constraints.maxEpochDay, calendar.supportedRange.max) as EpochDay,
  };
}

export function clampEpochDay(epochDay: EpochDay, bounds: CalendarBounds): EpochDay {
  return Math.min(Math.max(epochDay, bounds.min), bounds.max) as EpochDay;
}

export function fieldsOf(calendar: CalendarSystem, epochDay: EpochDay): DateFields {
  const fields = calendar.fromEpochDay(epochDay);
  if (!fields.isOk) throw new LunisolarPickerError(`${calendar.id} cannot read epoch day ${epochDay}: ${fields.error}`);
  return fields.value;
}

export function epochDayOfFields(calendar: CalendarSystem, fields: DateFields): EpochDay {
  const epochDay = calendar.toEpochDay(fields);
  if (!epochDay.isOk) {
    throw new LunisolarPickerError(`${calendar.id} cannot place ${fields.year} ${fields.monthCode} ${fields.day}: ${epochDay.error}`);
  }
  return epochDay.value;
}

export function firstEpochDayOfMonth(calendar: CalendarSystem, month: VisibleMonth): EpochDay {
  return epochDayOfFields(calendar, { ...month, day: 1 });
}

export function daysInVisibleMonth(calendar: CalendarSystem, month: VisibleMonth): number {
  return calendar.daysInMonth(month.year, month.monthCode);
}

export function supportedYearRange(calendar: CalendarSystem): { readonly firstYear: number; readonly lastYear: number } {
  return {
    firstYear: fieldsOf(calendar, calendar.supportedRange.min).year,
    lastYear: fieldsOf(calendar, calendar.supportedRange.max).year,
  };
}

// Goal: 휠·연도 이동처럼 조작 중에는 없는 날짜를 가장 가까운 유효한 날로 맞춤 (스펙 5.4, Temporal constrain과 같은 방향)
export function constrainDateFields(calendar: CalendarSystem, fields: DateFields): DateFields {
  const { firstYear, lastYear } = supportedYearRange(calendar);
  const year = Math.min(Math.max(fields.year, firstYear), lastYear);
  const monthCode = nearestMonthCode(calendar.monthsInYear(year), fields.monthCode);
  const day = Math.min(Math.max(fields.day, 1), calendar.daysInMonth(year, monthCode));
  const constrained: DateFields = { year, monthCode, day };
  if (calendar.toEpochDay(constrained).isOk) return constrained;
  return fieldsOf(calendar, calendar.supportedRange.max);
}

function nearestMonthCode(monthCodes: readonly MonthCode[], wanted: MonthCode): MonthCode {
  if (monthCodes.includes(wanted)) return wanted;
  const { month } = parseMonthCode(wanted);
  const regularCode = toMonthCode(month, false);
  if (monthCodes.includes(regularCode)) return regularCode;
  const earlierCodes = monthCodes.filter((code) => parseMonthCode(code).month <= month);
  const fallback = earlierCodes.at(-1) ?? monthCodes[0];
  if (!fallback) throw new LunisolarPickerError(`calendar returned no months while constraining ${wanted}`);
  return fallback;
}
```

```ts
import type { CalendarSystem, EpochDay, MonthCode } from '@lunisolar-picker/calendar';
import type { VisibleMonth } from '../types';
import { clampEpochDay, fieldsOf, firstEpochDayOfMonth, supportedYearRange } from './calendar-math';

export function shiftVisibleMonth(calendar: CalendarSystem, month: VisibleMonth, amount: number): VisibleMonth {
  const step = amount < 0 ? -1 : 1;
  let current = month;
  for (let moved = 0; moved < Math.abs(amount); moved += 1) {
    const adjacent = adjacentMonth(calendar, current, step);
    if (adjacent === null) break;
    current = adjacent;
  }
  return current;
}

export function visibleMonthOf(calendar: CalendarSystem, epochDay: EpochDay): VisibleMonth {
  const { year, monthCode } = fieldsOf(calendar, clampEpochDay(epochDay, calendar.supportedRange));
  return { year, monthCode };
}

export function compareVisibleMonths(calendar: CalendarSystem, first: VisibleMonth, second: VisibleMonth): number {
  return firstEpochDayOfMonth(calendar, first) - firstEpochDayOfMonth(calendar, second);
}

export function isSameVisibleMonth(first: VisibleMonth, second: VisibleMonth): boolean {
  return first.year === second.year && first.monthCode === second.monthCode;
}

export function listMonthsOfYear(calendar: CalendarSystem, year: number): readonly VisibleMonth[] {
  return calendar.monthsInYear(year).map((monthCode) => ({ year, monthCode }));
}

export function yearPageStartOf(year: number, pageSize: number): number {
  return year - (((year % pageSize) + pageSize) % pageSize);
}

export function listYearPage(calendar: CalendarSystem, pageStart: number, pageSize: number): readonly number[] {
  const { firstYear, lastYear } = supportedYearRange(calendar);
  return Array.from({ length: pageSize }, (_, index) => pageStart + index).filter(
    (year) => year >= firstYear && year <= lastYear,
  );
}

// Constraint: 범위 밖 연도에 monthsInYear를 부르면 프로그래머 오류로 던지므로 지원 연도를 먼저 확인함
function adjacentMonth(calendar: CalendarSystem, month: VisibleMonth, step: 1 | -1): VisibleMonth | null {
  const monthCodes = calendar.monthsInYear(month.year);
  const sameYearCode = monthCodes[monthCodes.indexOf(month.monthCode) + step];
  if (sameYearCode !== undefined) return { year: month.year, monthCode: sameYearCode };
  const { firstYear, lastYear } = supportedYearRange(calendar);
  const year = month.year + step;
  if (year < firstYear || year > lastYear) return null;
  const nextYearCodes = calendar.monthsInYear(year);
  const edgeCode: MonthCode | undefined = step > 0 ? nextYearCodes[0] : nextYearCodes.at(-1);
  return edgeCode === undefined ? null : { year, monthCode: edgeCode };
}
```

```ts
  gregory,

  parseMonthCode,

import { type SecondaryDateLabel, type VisibleMonth, type Weekday, toWeekday } from '../types';
import { daysInVisibleMonth, firstEpochDayOfMonth } from './calendar-math';

export interface MonthGridCell {
  readonly epochDay: EpochDay;
  readonly date: DateString;
  readonly day: number;
  readonly weekday: Weekday;
  readonly isOutsideMonth: boolean;
  readonly isOutsideSupportedRange: boolean;
  readonly secondary: SecondaryDateLabel | null;
}

export interface MonthGrid {
  readonly calendarId: CalendarId;
  readonly month: VisibleMonth;
  readonly weeks: readonly (readonly MonthGridCell[])[];
}

export interface BuildMonthGridOptions {
  readonly calendar: CalendarSystem;
  readonly month: VisibleMonth;
  readonly weekStartsOn: Weekday;
  readonly secondaryCalendar: CalendarSystem | null;
}

const DAYS_PER_WEEK = 7;
// Constraint: 달마다 줄 수가 바뀌면 팝오버 높이가 흔들리므로 항상 6주를 그림
const WEEKS_PER_GRID = 6;

export function buildMonthGrid(options: BuildMonthGridOptions): MonthGrid {
  const { calendar, month, weekStartsOn, secondaryCalendar } = options;
  const firstDay = firstEpochDayOfMonth(calendar, month);
  const lastDay = firstDay + daysInVisibleMonth(calendar, month) - 1;
  const leadingDayCount = (weekdayOf(firstDay) - weekStartsOn + DAYS_PER_WEEK) % DAYS_PER_WEEK;
  const gridStart = firstDay - leadingDayCount;
  const weeks = Array.from({ length: WEEKS_PER_GRID }, (_, weekIndex) =>
    Array.from({ length: DAYS_PER_WEEK }, (_, dayIndex) => {
      const epochDay = (gridStart + weekIndex * DAYS_PER_WEEK + dayIndex) as EpochDay;
      return buildCell(epochDay, calendar, epochDay >= firstDay && epochDay <= lastDay, secondaryCalendar);
    }),
  );
  return { calendarId: calendar.id, month, weeks };
}

function buildCell(
  epochDay: EpochDay,
  calendar: CalendarSystem,
  isInMonth: boolean,
  secondaryCalendar: CalendarSystem | null,
): MonthGridCell {
  const displayFields = calendar.fromEpochDay(epochDay);
  return {
    epochDay,
    date: dateStringOf(epochDay),
    day: displayFields.isOk ? displayFields.value.day : civilFromEpochDay(epochDay).day,
    weekday: toWeekday(weekdayOf(epochDay)),
    isOutsideMonth: !isInMonth,
    isOutsideSupportedRange: !displayFields.isOk || !isWithinSupportedRange(gregory, epochDay),
    secondary: secondaryCalendar === null ? null : secondaryLabelOf(secondaryCalendar, epochDay),
  };
}

// Constraint: 6주 격자의 앞뒤 칸은 양력 지원 범위(0001-01-01) 밖일 수 있음. 그 칸은 선택 불가(isOutsideSupportedRange)라 형식만 맞춘 문자열을 둠
function dateStringOf(epochDay: EpochDay): DateString {
  const formatted = formatDate(epochDay);
  if (formatted.isOk) return formatted.value;
  const { year, month, day } = civilFromEpochDay(epochDay);
  return `${padDigits(year, 4)}-${padDigits(month, 2)}-${padDigits(day, 2)}` as DateString;
}

function secondaryLabelOf(calendar: CalendarSystem, epochDay: EpochDay): SecondaryDateLabel | null {
  const fields = calendar.fromEpochDay(epochDay);
  if (!fields.isOk) return null;
  return {
    calendarId: calendar.id,
    monthCode: fields.value.monthCode,
    day: fields.value.day,
    isLeapMonth: parseMonthCode(fields.value.monthCode).isLeapMonth,
    isFirstDayOfMonth: fields.value.day === 1,
  };
}
```

```ts
import { type CalendarId, type CalendarSystem, type EpochDay, weekdayOf } from '@lunisolar-picker/calendar';
import { type PickerContext, findCalendar } from '../context';
import type { Reducer } from '../create-store';
import { boundsFor, clampEpochDay, constrainDateFields, epochDayOfFields, fieldsOf, supportedYearRange } from '../grid/calendar-math';
import {
  compareVisibleMonths,
  isSameVisibleMonth,
  shiftVisibleMonth,
  visibleMonthOf,
  yearPageStartOf,
} from '../grid/visible-month';
import type { VisibleMonth } from '../types';

export type CalendarView = 'days' | 'months' | 'years';
export type FocusUnit = 'day' | 'week' | 'month' | 'year';

export interface NavigationState {
  readonly displayCalendarId: CalendarId;
  readonly visibleMonth: VisibleMonth;
  readonly focusedEpochDay: EpochDay;
  readonly view: CalendarView;
  readonly yearPageStart: number;
}

export type NavigationEvent =
  | { readonly type: 'month.shift'; readonly amount: number }
  | { readonly type: 'today.go' }
  | { readonly type: 'focus.set'; readonly epochDay: EpochDay }
  | { readonly type: 'focus.move'; readonly unit: FocusUnit; readonly amount: number }
  | { readonly type: 'focus.weekEdge'; readonly edge: 'start' | 'end' }
  | { readonly type: 'view.set'; readonly view: CalendarView }
  | { readonly type: 'month.pick'; readonly month: VisibleMonth }
  | { readonly type: 'year.pick'; readonly year: number }
  | { readonly type: 'yearPage.shift'; readonly amount: number }
  | { readonly type: 'calendar.set'; readonly calendarId: CalendarId };

export const YEAR_PAGE_SIZE = 12;
const DAYS_PER_WEEK = 7;

export function createNavigationState(
  context: PickerContext,
  initial: { readonly focusedEpochDay?: EpochDay; readonly displayCalendarId?: CalendarId } = {},
): NavigationState {
  const displayCalendarId = initial.displayCalendarId ?? 'gregory';
  const calendar = findCalendar(context.calendars, displayCalendarId);
  const focusedEpochDay = clampEpochDay(initial.focusedEpochDay ?? context.today, boundsFor(calendar, context.constraints));
  const visibleMonth = visibleMonthOf(calendar, focusedEpochDay);
  return {
    displayCalendarId,
    visibleMonth,
    focusedEpochDay,
    view: 'days',
    yearPageStart: yearPageStartOf(visibleMonth.year, YEAR_PAGE_SIZE),
  };
}

export const navigationReducer: Reducer<NavigationState, NavigationEvent, PickerContext> = (state, event, context) => {
  const calendar = findCalendar(context.calendars, state.displayCalendarId);
  switch (event.type) {
    case 'month.shift':
      return shiftMonths(state, event.amount, calendar, context);
    case 'today.go':
      return mergeNavigation(state, { ...focusAsFirstMonth(context.today, calendar, context), view: 'days' });
    case 'focus.set':
      return focusOn(state, event.epochDay, calendar, context);
    case 'focus.move':
      return focusOn(state, movedEpochDay(state.focusedEpochDay, event.unit, event.amount, calendar), calendar, context);
    case 'focus.weekEdge':
      return focusOn(state, weekEdgeOf(state.focusedEpochDay, event.edge, context), calendar, context);
    case 'view.set':
      return mergeNavigation(state, {
        view: event.view,
        yearPageStart: event.view === 'years' ? yearPageStartOf(state.visibleMonth.year, YEAR_PAGE_SIZE) : state.yearPageStart,
      });
    case 'month.pick':
      return pickMonth(state, event.month, calendar, context);
    case 'year.pick':
      return pickYear(state, event.year, calendar);
    case 'yearPage.shift':
      return shiftYearPage(state, event.amount, calendar);
    case 'calendar.set':
      return switchCalendar(state, event.calendarId, context);
  }
};

function focusOn(state: NavigationState, epochDay: EpochDay, calendar: CalendarSystem, context: PickerContext): NavigationState {
  const focusedEpochDay = clampEpochDay(epochDay, boundsFor(calendar, context.constraints));
  const visibleMonth = keepFocusVisible(calendar, state.visibleMonth, focusedEpochDay, context.numberOfMonths);
  return mergeNavigation(state, { focusedEpochDay, visibleMonth });
}

function focusAsFirstMonth(
  epochDay: EpochDay,
  calendar: CalendarSystem,
  context: PickerContext,
): Pick<NavigationState, 'focusedEpochDay' | 'visibleMonth'> {
  const focusedEpochDay = clampEpochDay(epochDay, boundsFor(calendar, context.constraints));
  return { focusedEpochDay, visibleMonth: visibleMonthOf(calendar, focusedEpochDay) };
}

// Goal: 여러 달을 보여 줄 때 포커스가 보이는 달 안에서 움직이면 화면을 흔들지 않음
function keepFocusVisible(
  calendar: CalendarSystem,
  visibleMonth: VisibleMonth,
  focusedEpochDay: EpochDay,
  numberOfMonths: number,
): VisibleMonth {
  const focusMonth = visibleMonthOf(calendar, focusedEpochDay);
  if (compareVisibleMonths(calendar, focusMonth, visibleMonth) < 0) return focusMonth;
  const lastVisibleMonth = shiftVisibleMonth(calendar, visibleMonth, numberOfMonths - 1);
  if (compareVisibleMonths(calendar, focusMonth, lastVisibleMonth) <= 0) return visibleMonth;
  return shiftVisibleMonth(calendar, focusMonth, -(numberOfMonths - 1));
}

function shiftMonths(state: NavigationState, amount: number, calendar: CalendarSystem, context: PickerContext): NavigationState {
  const visibleMonth = shiftVisibleMonth(calendar, state.visibleMonth, amount);
  const focusedEpochDay = clampEpochDay(
    movedEpochDay(state.focusedEpochDay, 'month', amount, calendar),
    boundsFor(calendar, context.constraints),
  );
  return mergeNavigation(state, {
    visibleMonth: keepFocusVisible(calendar, visibleMonth, focusedEpochDay, context.numberOfMonths),
    focusedEpochDay,
  });
}

function movedEpochDay(epochDay: EpochDay, unit: FocusUnit, amount: number, calendar: CalendarSystem): EpochDay {
  if (unit === 'day') return (epochDay + amount) as EpochDay;
  if (unit === 'week') return (epochDay + amount * DAYS_PER_WEEK) as EpochDay;
  const fields = fieldsOf(calendar, epochDay);
  if (unit === 'year') return epochDayOfFields(calendar, constrainDateFields(calendar, { ...fields, year: fields.year + amount }));
  const targetMonth = shiftVisibleMonth(calendar, { year: fields.year, monthCode: fields.monthCode }, amount);
  return epochDayOfFields(calendar, constrainDateFields(calendar, { ...targetMonth, day: fields.day }));
}

function weekEdgeOf(epochDay: EpochDay, edge: 'start' | 'end', context: PickerContext): EpochDay {
  const offsetFromStart = (weekdayOf(epochDay) - context.weekStartsOn + DAYS_PER_WEEK) % DAYS_PER_WEEK;
  const weekStart = epochDay - offsetFromStart;
  return (edge === 'start' ? weekStart : weekStart + DAYS_PER_WEEK - 1) as EpochDay;
}

function pickMonth(state: NavigationState, month: VisibleMonth, calendar: CalendarSystem, context: PickerContext): NavigationState {
  const focusDay = fieldsOf(calendar, state.focusedEpochDay).day;
  const focusedEpochDay = clampEpochDay(
    epochDayOfFields(calendar, constrainDateFields(calendar, { ...month, day: focusDay })),
    boundsFor(calendar, context.constraints),
  );
  return mergeNavigation(state, { view: 'days', visibleMonth: visibleMonthOf(calendar, focusedEpochDay), focusedEpochDay });
}

function pickYear(state: NavigationState, year: number, calendar: CalendarSystem): NavigationState {
  const constrained = constrainDateFields(calendar, { year, monthCode: state.visibleMonth.monthCode, day: 1 });
  return mergeNavigation(state, { view: 'months', visibleMonth: { year: constrained.year, monthCode: constrained.monthCode } });
}

function shiftYearPage(state: NavigationState, amount: number, calendar: CalendarSystem): NavigationState {
  const { firstYear, lastYear } = supportedYearRange(calendar);
  const firstPageStart = yearPageStartOf(firstYear, YEAR_PAGE_SIZE);
  const lastPageStart = yearPageStartOf(lastYear, YEAR_PAGE_SIZE);
  const yearPageStart = Math.min(Math.max(state.yearPageStart + amount * YEAR_PAGE_SIZE, firstPageStart), lastPageStart);
  return mergeNavigation(state, { yearPageStart });
}

function switchCalendar(state: NavigationState, calendarId: CalendarId, context: PickerContext): NavigationState {
  const calendar = findCalendar(context.calendars, calendarId);
  const focus = focusAsFirstMonth(state.focusedEpochDay, calendar, context);
  return mergeNavigation(state, {
    ...focus,
    displayCalendarId: calendarId,
    yearPageStart: yearPageStartOf(focus.visibleMonth.year, YEAR_PAGE_SIZE),
  });
}

// Constraint: 바뀐 값이 없으면 같은 참조를 돌려줘야 createStore가 구독자를 깨우지 않음
function mergeNavigation(state: NavigationState, changes: Partial<NavigationState>): NavigationState {
  const next = { ...state, ...changes };
  const isUnchanged =
    next.displayCalendarId === state.displayCalendarId &&
    isSameVisibleMonth(next.visibleMonth, state.visibleMonth) &&
    next.focusedEpochDay === state.focusedEpochDay &&
    next.view === state.view &&
    next.yearPageStart === state.yearPageStart;
  return isUnchanged ? state : next;
}
```

```ts
import { type CalendarId, type DateString, type EpochDay, formatDate } from '@lunisolar-picker/calendar';
import { type PickerContext, findCalendar } from '../context';
import type { Reducer } from '../create-store';
import { type SelectedDay, isSelectableDay } from './selectable';

export interface SingleSelectionState {
  readonly committed: SelectedDay | null;
  readonly draft: SelectedDay | null;
}

export type SingleSelectionEvent =
  | { readonly type: 'date.select'; readonly epochDay: EpochDay; readonly calendarId: CalendarId }
  | { readonly type: 'commit' }
  | { readonly type: 'cancel' }
  | { readonly type: 'clear' }
  | { readonly type: 'value.sync'; readonly selected: SelectedDay | null };

export function createSingleSelectionState(committed: SelectedDay | null): SingleSelectionState {
  return { committed, draft: committed };
}

export const singleSelectionReducer: Reducer<SingleSelectionState, SingleSelectionEvent, PickerContext> = (
  state,
  event,
  context,
) => {
  switch (event.type) {
    case 'date.select':
      return selectDay(state, { epochDay: event.epochDay, calendarId: event.calendarId }, context);
    case 'commit':
      return isSameSelectedDay(state.committed, state.draft) ? state : { ...state, committed: state.draft };
    case 'cancel':
      return isSameSelectedDay(state.committed, state.draft) ? state : { ...state, draft: state.committed };
    case 'clear':
      return clearSelection(state, context);
    case 'value.sync':
      return isSameSelectedDay(state.committed, event.selected) && isSameSelectedDay(state.draft, event.selected)
        ? state
        : createSingleSelectionState(event.selected);
  }
};

export function singleValue(state: SingleSelectionState, context: PickerContext): DateString | null {
  return state.committed === null ? null : formatSelectedDay(state.committed, context);
}

export function formatSelectedDay(selected: SelectedDay, context: PickerContext): DateString | null {
  const formatted = formatDate(selected.epochDay, findCalendar(context.calendars, selected.calendarId));
  return formatted.isOk ? formatted.value : null;
}

function selectDay(state: SingleSelectionState, selected: SelectedDay, context: PickerContext): SingleSelectionState {
  if (!isSelectableDay(selected.epochDay, findCalendar(context.calendars, selected.calendarId), context)) return state;
  if (context.commitMode === 'confirm') {
    return isSameSelectedDay(state.draft, selected) ? state : { ...state, draft: selected };
  }
  return isSameSelectedDay(state.committed, selected) && isSameSelectedDay(state.draft, selected)
    ? state
    : { committed: selected, draft: selected };
}

function clearSelection(state: SingleSelectionState, context: PickerContext): SingleSelectionState {
  const committed = context.commitMode === 'immediate' ? null : state.committed;
  return state.draft === null && state.committed === committed ? state : { committed, draft: null };
}

function isSameSelectedDay(first: SelectedDay | null, second: SelectedDay | null): boolean {
  if (first === null || second === null) return first === second;
  return first.epochDay === second.epochDay && first.calendarId === second.calendarId;
}
```

```ts
import { type CalendarId, type DateRangeValue, type EpochDay, formatDate } from '@lunisolar-picker/calendar';
import { isEpochDayInBlockedRange, validateEpochRange } from '../constraints/validate';
import { type PickerContext, findCalendar } from '../context';
import type { Reducer } from '../create-store';
import { type EpochRange, type Validity, invalidBecause } from '../types';
import { isSelectableDay } from './selectable';

export type RangePointerPhase = 'idle' | 'pressing' | 'dragging';
export type RangeHandle = 'start' | 'end';

export interface SelectedRange {
  readonly range: EpochRange;
  readonly calendarId: CalendarId;
}

export interface RangeSelectionState {
  readonly committed: SelectedRange | null;
  readonly draft: SelectedRange | null;
  readonly anchor: EpochDay | null;
  readonly preview: EpochDay | null;
  readonly grabbedHandle: RangeHandle | null;
  readonly pointerPhase: RangePointerPhase;
  readonly pendingCalendarId: CalendarId;
}

export type RangeSelectionEvent =
  | { readonly type: 'pointer.down'; readonly epochDay: EpochDay; readonly calendarId: CalendarId }
  | { readonly type: 'pointer.enter'; readonly epochDay: EpochDay }
  | { readonly type: 'pointer.up' }
  | { readonly type: 'handle.grab'; readonly handle: RangeHandle }
  | { readonly type: 'date.select'; readonly epochDay: EpochDay; readonly calendarId: CalendarId }
  | { readonly type: 'range.set'; readonly range: EpochRange; readonly calendarId: CalendarId }
  | { readonly type: 'commit' }
  | { readonly type: 'cancel' }
  | { readonly type: 'clear' }
  | { readonly type: 'value.sync'; readonly selected: SelectedRange | null };

const IDLE_TRANSIENT = { anchor: null, preview: null, grabbedHandle: null, pointerPhase: 'idle' } as const;

export function createRangeSelectionState(committed: SelectedRange | null): RangeSelectionState {
  return { committed, draft: committed, ...IDLE_TRANSIENT, pendingCalendarId: committed?.calendarId ?? 'gregory' };
}

export const rangeSelectionReducer: Reducer<RangeSelectionState, RangeSelectionEvent, PickerContext> = (
  state,
  event,
  context,
) => {
  switch (event.type) {
    case 'date.select':
      return selectEndpoint(state, event.epochDay, state.anchor === null ? event.calendarId : state.pendingCalendarId, context);
    case 'pointer.down':
      return pressDay(state, event.epochDay, event.calendarId, context);
    case 'pointer.enter':
      return enterDay(state, event.epochDay, context);
    case 'pointer.up':
      return releasePointer(state, context);
    case 'handle.grab':
      return grabHandle(state, event.handle);
    case 'range.set':
      return setRange(state, event.range, event.calendarId, context);
    case 'commit':
      return commitDraft(state, context);
    case 'cancel':
      return resetTo(state, state.committed, state.committed);
    case 'clear':
      return resetTo(state, context.commitMode === 'immediate' ? null : state.committed, null);
    case 'value.sync':
      return resetTo(state, event.selected, event.selected);
  }
};

export function displayedRange(state: RangeSelectionState): EpochRange | null {
  if (state.anchor === null) return state.draft?.range ?? null;
  return state.preview === null ? { start: state.anchor, end: null } : sortedRange(state.anchor, state.preview);
}

export function rangeValidity(state: RangeSelectionState, context: PickerContext): Validity {
  const range = displayedRange(state);
  return range === null ? invalidBecause(['incomplete']) : validateEpochRange(range, context.constraints);
}

export function rangeValue(state: RangeSelectionState, context: PickerContext): DateRangeValue | null {
  if (state.committed === null) return null;
  const calendar = findCalendar(context.calendars, state.committed.calendarId);
  const start = formatDate(state.committed.range.start, calendar);
  const end = state.committed.range.end === null ? null : formatDate(state.committed.range.end, calendar);
  if (!start.isOk || (end !== null && !end.isOk)) return null;
  return { start: start.value, end: end === null ? null : end.value };
}

function isSelectable(epochDay: EpochDay, calendarId: CalendarId, anchor: EpochDay | null, context: PickerContext): boolean {
  if (!isSelectableDay(epochDay, findCalendar(context.calendars, calendarId), context)) return false;
  return anchor === null || !isEpochDayInBlockedRange(anchor, epochDay, context.constraints);
}

function selectEndpoint(
  state: RangeSelectionState,
  epochDay: EpochDay,
  calendarId: CalendarId,
  context: PickerContext,
): RangeSelectionState {
  if (!isSelectable(epochDay, calendarId, state.anchor, context)) return state;
  if (state.anchor === null) return startRange(state, epochDay, calendarId);
  return completeRange(state, state.anchor, epochDay, context);
}

// Goal: 완성된 범위에서 다시 고르면 새 범위를 시작함 (web-console 정책과 같음)
function startRange(state: RangeSelectionState, epochDay: EpochDay, calendarId: CalendarId): RangeSelectionState {
  return {
    ...state,
    ...IDLE_TRANSIENT,
    anchor: epochDay,
    pendingCalendarId: calendarId,
    draft: { range: { start: epochDay, end: null }, calendarId },
  };
}

function completeRange(
  state: RangeSelectionState,
  anchor: EpochDay,
  other: EpochDay,
  context: PickerContext,
): RangeSelectionState {
  const draft: SelectedRange = { range: sortedRange(anchor, other), calendarId: state.pendingCalendarId };
  return {
    ...state,
    ...IDLE_TRANSIENT,
    draft,
    committed: context.commitMode === 'immediate' ? draft : state.committed,
  };
}

function pressDay(
  state: RangeSelectionState,
  epochDay: EpochDay,
  calendarId: CalendarId,
  context: PickerContext,
): RangeSelectionState {
  if (state.anchor !== null) return selectEndpoint(state, epochDay, state.pendingCalendarId, context);
  if (!isSelectable(epochDay, calendarId, null, context)) return state;
  return { ...startRange(state, epochDay, calendarId), pointerPhase: 'pressing' };
}

// Constraint: 막힌 날짜 위를 지나면 미리보기는 직전 유효한 날에 머묾 (Review Focus 5)
function enterDay(state: RangeSelectionState, epochDay: EpochDay, context: PickerContext): RangeSelectionState {
  if (state.anchor === null || epochDay === (state.preview ?? state.anchor)) return state;
  if (!isSelectable(epochDay, state.pendingCalendarId, state.anchor, context)) return state;
  return { ...state, preview: epochDay, pointerPhase: state.pointerPhase === 'idle' ? 'idle' : 'dragging' };
}

function releasePointer(state: RangeSelectionState, context: PickerContext): RangeSelectionState {
  if (state.pointerPhase === 'dragging' && state.anchor !== null) {
    return completeRange(state, state.anchor, state.preview ?? state.anchor, context);
  }
  if (state.pointerPhase !== 'pressing') return state;
  if (state.grabbedHandle !== null && state.preview !== null) return startRange(state, state.preview, state.pendingCalendarId);
  return { ...state, pointerPhase: 'idle' };
}

function grabHandle(state: RangeSelectionState, handle: RangeHandle): RangeSelectionState {
  const range = state.draft?.range;
  if (!state.draft || !range || range.end === null || state.anchor !== null) return state;
  const isStart = handle === 'start';
  return {
    ...state,
    anchor: isStart ? range.end : range.start,
    preview: isStart ? range.start : range.end,
    grabbedHandle: handle,
    pointerPhase: 'pressing',
    pendingCalendarId: state.draft.calendarId,
  };
}

function setRange(
  state: RangeSelectionState,
  range: EpochRange,
  calendarId: CalendarId,
  context: PickerContext,
): RangeSelectionState {
  if (range.end === null && !context.constraints.isOpenEndAllowed) return state;
  const draft: SelectedRange = { range: range.end === null ? range : sortedRange(range.start, range.end), calendarId };
  return {
    ...state,
    ...IDLE_TRANSIENT,
    pendingCalendarId: calendarId,
    draft,
    committed: context.commitMode === 'immediate' ? draft : state.committed,
  };
}

function commitDraft(state: RangeSelectionState, context: PickerContext): RangeSelectionState {
  if (state.anchor !== null || state.draft === null || isSameSelectedRange(state.draft, state.committed)) return state;
  if (state.draft.range.end === null && !context.constraints.isOpenEndAllowed) return state;
  return { ...state, committed: state.draft };
}

function resetTo(state: RangeSelectionState, committed: SelectedRange | null, draft: SelectedRange | null): RangeSelectionState {
  const isUnchanged =
    isSameSelectedRange(state.committed, committed) &&
    isSameSelectedRange(state.draft, draft) &&
    state.anchor === null &&
    state.pointerPhase === 'idle';
  if (isUnchanged) return state;
  return { ...state, ...IDLE_TRANSIENT, committed, draft, pendingCalendarId: draft?.calendarId ?? state.pendingCalendarId };
}

function sortedRange(first: EpochDay, second: EpochDay): EpochRange {
  return first <= second ? { start: first, end: second } : { start: second, end: first };
}

function isSameSelectedRange(first: SelectedRange | null, second: SelectedRange | null): boolean {
  if (first === null || second === null) return first === second;
  return (
    first.calendarId === second.calendarId && first.range.start === second.range.start && first.range.end === second.range.end
  );
}
```

```ts
export interface SegmentLimits {
  readonly minValue: number;
  readonly maxValue: number;
  readonly maxDigits: number;
}

export interface Segment<Kind extends string> extends SegmentLimits {
  readonly kind: Kind;
  readonly value: number | null;
  readonly typedText: string;
}

export interface SegmentGroup<Kind extends string> {
  readonly segments: readonly Segment<Kind>[];
  readonly focusedIndex: number | null;
}

export type SegmentEvent =
  | { readonly type: 'segment.focus'; readonly index: number }
  | { readonly type: 'segment.blur' }
  | { readonly type: 'digit.type'; readonly digit: number }
  | { readonly type: 'separator.type' }
  | { readonly type: 'segment.erase' }
  | { readonly type: 'segment.step'; readonly amount: number }
  | { readonly type: 'focus.shift'; readonly amount: number };

export interface TypedDigit<Kind extends string> {
  readonly segment: Segment<Kind>;
  readonly shouldAdvance: boolean;
}

export function createSegment<Kind extends string>(kind: Kind, limits: SegmentLimits, value: number | null): Segment<Kind> {
  return { kind, ...limits, value, typedText: '' };
}

// Goal: 다음 숫자가 들어갈 자리가 없으면 바로 다음 칸으로 넘김 (예: 월 칸에 3 → 03, 시 칸에 9 → 09)
export function typeDigit<Kind extends string>(segment: Segment<Kind>, digit: number): TypedDigit<Kind> {
  const appended = `${segment.typedText}${digit}`;
  const isOverflowing = appended.length > segment.maxDigits || Number(appended) > segment.maxValue;
  const typedText = isOverflowing ? String(digit) : appended;
  const canTakeAnotherDigit = typedText.length < segment.maxDigits && Number(`${typedText}0`) <= segment.maxValue;
  return { segment: { ...segment, typedText, value: Number(typedText) }, shouldAdvance: !canTakeAnotherDigit };
}

export function eraseDigit<Kind extends string>(segment: Segment<Kind>): Segment<Kind> {
  if (segment.typedText === '') return { ...segment, value: null };
  const typedText = segment.typedText.slice(0, -1);
  return { ...segment, typedText, value: typedText === '' ? null : Number(typedText) };
}

export function stepSegment<Kind extends string>(segment: Segment<Kind>, amount: number, startValue: number): Segment<Kind> {
  if (segment.value === null) return { ...segment, value: startValue, typedText: '' };
  const span = segment.maxValue - segment.minValue + 1;
  const offset = (((segment.value - segment.minValue + amount) % span) + span) % span;
  return { ...segment, value: segment.minValue + offset, typedText: '' };
}

export function withSegmentValue<Kind extends string>(segment: Segment<Kind>, value: number | null): Segment<Kind> {
  return { ...segment, value, typedText: '' };
}

export function focusSegmentAt<Kind extends string, Group extends SegmentGroup<Kind>>(group: Group, index: number | null): Group {
  const focusedIndex = index === null ? null : Math.min(Math.max(index, 0), group.segments.length - 1);
  const hasTypedText = group.segments.some((segment) => segment.typedText !== '');
  if (focusedIndex === group.focusedIndex && !hasTypedText) return group;
  return { ...group, focusedIndex, segments: group.segments.map((segment) => ({ ...segment, typedText: '' })) };
}

export function replaceFocusedSegment<Kind extends string, Group extends SegmentGroup<Kind>>(
  group: Group,
  segment: Segment<Kind>,
): Group {
  if (group.focusedIndex === null) return group;
  const index = group.focusedIndex;
  return { ...group, segments: group.segments.map((current, currentIndex) => (currentIndex === index ? segment : current)) };
}

// Goal: 날짜·시간 필드가 공유하는 키 입력 규칙을 한 곳에 둠. 칸 종류별 차이는 stepStartValue로만 받음
export function reduceSegmentEvent<Kind extends string, Group extends SegmentGroup<Kind>>(
  group: Group,
  event: SegmentEvent,
  stepStartValue: (kind: Kind) => number,
): Group {
  const focused = group.focusedIndex === null ? undefined : group.segments[group.focusedIndex];
  switch (event.type) {
    case 'segment.focus':
      return focusSegmentAt<Kind, Group>(group, event.index);
    case 'segment.blur':
      return focusSegmentAt<Kind, Group>(group, null);
    case 'focus.shift':
      return group.focusedIndex === null ? group : focusSegmentAt<Kind, Group>(group, group.focusedIndex + event.amount);
    case 'digit.type':
      return focused ? typeIntoGroup(group, focused, event.digit) : group;
    case 'separator.type':
      return focused && focused.typedText !== '' && group.focusedIndex !== null
        ? focusSegmentAt<Kind, Group>(group, group.focusedIndex + 1)
        : group;
    case 'segment.erase':
      return focused ? replaceFocusedSegment(group, eraseDigit(focused)) : group;
    case 'segment.step':
      return focused ? replaceFocusedSegment(group, stepSegment(focused, event.amount, stepStartValue(focused.kind))) : group;
  }
}

function typeIntoGroup<Kind extends string, Group extends SegmentGroup<Kind>>(
  group: Group,
  focused: Segment<Kind>,
  digit: number,
): Group {
  const { segment, shouldAdvance } = typeDigit(focused, digit);
  const replaced = replaceFocusedSegment(group, segment);
  const isLastSegment = group.focusedIndex === group.segments.length - 1;
  if (!shouldAdvance || isLastSegment || group.focusedIndex === null) return replaced;
  return { ...replaced, focusedIndex: group.focusedIndex + 1 };
}
```

```ts
import type { Reducer } from '../create-store';
import { fieldsOf } from '../grid/calendar-math';
import { type DateSegmentKind, VALID, type Validity, invalidBecause } from '../types';

import {
  type Segment,
  type SegmentEvent,
  type SegmentGroup,
  type SegmentLimits,
  createSegment,
  reduceSegmentEvent,
  replaceFocusedSegment,
  withSegmentValue,

export interface DateFieldState extends SegmentGroup<DateSegmentKind> {
  readonly isLeapMonth: boolean;
  readonly entryCalendarId: CalendarId;
}

export type DateFieldEvent =
  | SegmentEvent
  | { readonly type: 'text.paste'; readonly text: string }
  | { readonly type: 'leapMonth.toggle' }
  | { readonly type: 'calendar.set'; readonly calendarId: CalendarId }
  | { readonly type: 'value.sync'; readonly selected: SelectedDay | null; readonly entryCalendarId: CalendarId };

export interface DateFieldResult {
  readonly epochDay: EpochDay | null;
  readonly validity: Validity;
}

type DateParts = Readonly<Record<DateSegmentKind, number>>;

const SEGMENT_LIMITS: Readonly<Record<DateSegmentKind, SegmentLimits>> = {
  year: { minValue: 1, maxValue: 9999, maxDigits: 4 },
  month: { minValue: 1, maxValue: 12, maxDigits: 2 },
  // Constraint: 달 길이는 연·월이 다 들어와야 알 수 있어 입력 중에는 31까지 받고, 결과에서 역법이 판정함 (스펙 5.4)
  day: { minValue: 1, maxValue: 31, maxDigits: 2 },
};
const ISO_ORDER: readonly DateSegmentKind[] = ['year', 'month', 'day'];
const COMPACT_DATE_LENGTH = 8;
const YEAR_DIGITS = 4;

export function createDateFieldState(
  context: PickerContext,
  initial: { readonly selected: SelectedDay | null; readonly entryCalendarId: CalendarId },
): DateFieldState {
  const calendarId = initial.selected?.calendarId ?? initial.entryCalendarId;
  const parts = initial.selected === null ? null : partsOf(findCalendar(context.calendars, calendarId), initial.selected.epochDay);
  return {
    segments: context.locale.field.order.map((kind) => createSegment(kind, SEGMENT_LIMITS[kind], parts?.values[kind] ?? null)),
    focusedIndex: null,
    isLeapMonth: parts?.isLeapMonth ?? false,
    entryCalendarId: calendarId,
  };
}

export const dateFieldReducer: Reducer<DateFieldState, DateFieldEvent, PickerContext> = (state, event, context) => {
  switch (event.type) {
    case 'text.paste':
      return pasteDate(state, event.text, context);
    case 'leapMonth.toggle':
      return state.entryCalendarId === gregory.id ? state : { ...state, isLeapMonth: !state.isLeapMonth };
    case 'calendar.set':
      return switchEntryCalendar(state, event.calendarId, context);
    case 'value.sync':
      return { ...createDateFieldState(context, event), focusedIndex: state.focusedIndex };
    case 'segment.step':
      return stepDateSegment(state, event.amount, context);
    default:
      return reduceSegmentEvent<DateSegmentKind, DateFieldState>(state, event, (kind) => todayPart(kind, state, context));
  }
};

export function dateFieldResult(state: DateFieldState, context: PickerContext): DateFieldResult {
  const values = state.segments.map((segment) => segment.value);
  if (values.every((value) => value === null)) return { epochDay: null, validity: VALID };
  if (values.some((value) => value === null)) return { epochDay: null, validity: invalidBecause(['incomplete']) };
  const parts = partsFromSegments(state.segments);
  if (parts.month < 1 || parts.month > 12 || parts.year < 1 || parts.day < 1) {
    return { epochDay: null, validity: invalidBecause(['invalid-date']) };
  }
  const calendar = findCalendar(context.calendars, state.entryCalendarId);
  const epochDay = calendar.toEpochDay({ year: parts.year, monthCode: toMonthCode(parts.month, state.isLeapMonth), day: parts.day });
  if (!epochDay.isOk) return { epochDay: null, validity: invalidBecause([epochDay.error]) };
  return { epochDay: epochDay.value, validity: validateEpochDay(epochDay.value, context.constraints) };
}

function partsOf(calendar: CalendarSystem, epochDay: EpochDay): { readonly values: DateParts; readonly isLeapMonth: boolean } {
  const fields = fieldsOf(calendar, epochDay);
  const { month, isLeapMonth } = parseMonthCode(fields.monthCode);
  return { values: { year: fields.year, month, day: fields.day }, isLeapMonth };
}

function partsFromSegments(segments: readonly Segment<DateSegmentKind>[]): DateParts {
  const valueOf = (kind: DateSegmentKind): number => segments.find((segment) => segment.kind === kind)?.value ?? 0;
  return { year: valueOf('year'), month: valueOf('month'), day: valueOf('day') };
}

function todayPart(kind: DateSegmentKind, state: DateFieldState, context: PickerContext): number {
  const calendar = findCalendar(context.calendars, state.entryCalendarId);
  return partsOf(calendar, context.today).values[kind];
}

// Goal: 월 칸 ↑↓는 그해 실제 달 순서(윤달 포함)를 따라감. 양력도 같은 경로를 써서 역법 종류로 분기하지 않음
function stepDateSegment(state: DateFieldState, amount: number, context: PickerContext): DateFieldState {
  const focused = state.focusedIndex === null ? undefined : state.segments[state.focusedIndex];
  const startValue = (kind: DateSegmentKind): number => todayPart(kind, state, context);
  if (!focused || focused.kind !== 'month') {
    return reduceSegmentEvent<DateSegmentKind, DateFieldState>(state, { type: 'segment.step', amount }, startValue);
  }
  const calendar = findCalendar(context.calendars, state.entryCalendarId);
  const year = state.segments.find((segment) => segment.kind === 'year')?.value ?? null;
  const monthCodes = year === null ? null : monthCodesIfSupported(calendar, year);
  if (monthCodes === null || focused.value === null) {
    return reduceSegmentEvent<DateSegmentKind, DateFieldState>(state, { type: 'segment.step', amount }, startValue);
  }
  const currentIndex = Math.max(monthCodes.indexOf(toMonthCode(focused.value, state.isLeapMonth)), 0);
  const nextCode = monthCodes[(((currentIndex + amount) % monthCodes.length) + monthCodes.length) % monthCodes.length];
  if (nextCode === undefined) return state;
  const { month, isLeapMonth } = parseMonthCode(nextCode);
  return { ...replaceFocusedSegment(state, withSegmentValue(focused, month)), isLeapMonth };
}

function monthCodesIfSupported(calendar: CalendarSystem, year: number): readonly MonthCode[] | null {
  const firstYear = fieldsOf(calendar, calendar.supportedRange.min).year;
  const lastYear = fieldsOf(calendar, calendar.supportedRange.max).year;
  return year < firstYear || year > lastYear ? null : calendar.monthsInYear(year);
}

function pasteDate(state: DateFieldState, text: string, context: PickerContext): DateFieldState {
  const parts = readPastedParts(text, context.locale.field.order);
  if (parts === null) return state;
  return {
    ...state,
    isLeapMonth: false,
    segments: state.segments.map((segment) => withSegmentValue(segment, parts[segment.kind])),
  };
}

// Goal: 붙여넣기는 숫자만 추림. 첫 덩어리가 네 자리면 연-월-일(ISO) 순서로 보고, 아니면 로케일 순서를 따름 (Review Focus 4)
function readPastedParts(text: string, localeOrder: readonly DateSegmentKind[]): DateParts | null {
  const digitGroups = text.match(/\d+/g) ?? [];
  const [onlyGroup] = digitGroups;
  if (digitGroups.length === 1 && onlyGroup?.length === COMPACT_DATE_LENGTH) {
    return { year: Number(onlyGroup.slice(0, 4)), month: Number(onlyGroup.slice(4, 6)), day: Number(onlyGroup.slice(6, 8)) };
  }
  if (digitGroups.length !== ISO_ORDER.length) return null;
  const order = digitGroups[0]?.length === YEAR_DIGITS ? ISO_ORDER : localeOrder;
  const valueOf = (kind: DateSegmentKind): number => Number(digitGroups[order.indexOf(kind)]);
  return { year: valueOf('year'), month: valueOf('month'), day: valueOf('day') };
}

function switchEntryCalendar(state: DateFieldState, calendarId: CalendarId, context: PickerContext): DateFieldState {
  if (calendarId === state.entryCalendarId) return state;
  const { epochDay } = dateFieldResult(state, context);
  const calendar = findCalendar(context.calendars, calendarId);
  const isConvertible = epochDay !== null && calendar.fromEpochDay(epochDay).isOk;
  if (!isConvertible || epochDay === null) return { ...state, entryCalendarId: calendarId, isLeapMonth: false };
  const parts = partsOf(calendar, epochDay);
  return {
    ...state,
    entryCalendarId: calendarId,
    isLeapMonth: parts.isLeapMonth,
    segments: state.segments.map((segment) => withSegmentValue(segment, parts.values[segment.kind])),
  };
}
```

```ts
export function timeFieldResult(state: TimeFieldState, context: TimeFieldContext): TimeFieldResult {
  const [hour = null, minute = null] = state.segments.map((segment) => segment.value);
  if (hour === null && minute === null) return { time: null, validity: VALID };
  if (hour === null || minute === null) return { time: null, validity: invalidBecause(['incomplete']) };
  const time = formatTime(hour, minute, { isEndOfDayAllowed: context.isEndOfDayAllowed });
  return time.isOk ? { time: time.value, validity: VALID } : { time: null, validity: invalidBecause([time.error]) };
}

// Goal: 분 칸 ↑↓는 간격 배수로 맞춤 (07에서 5분 간격 ↑ → 10, ↓ → 05). web-console TimeSelector의 5분 단위를 대체
function stepTimeSegment(state: TimeFieldState, amount: number, context: TimeFieldContext): TimeFieldState {
  const focused = state.focusedIndex === null ? undefined : state.segments[state.focusedIndex];
  if (!focused || focused.kind !== 'minute' || focused.value === null) {
    return reduceSegmentEvent<TimeSegmentKind, TimeFieldState>(state, { type: 'segment.step', amount }, () => 0);
  }
  const step = context.minuteStep;
  const alignedBase = amount > 0 ? Math.floor(focused.value / step) * step : Math.ceil(focused.value / step) * step;
  const minute = (((alignedBase + amount * step) % MINUTES_PER_HOUR) + MINUTES_PER_HOUR) % MINUTES_PER_HOUR;
  return replaceFocusedSegment(state, withSegmentValue(focused, minute));
}

function pasteTime(state: TimeFieldState, text: string): TimeFieldState {
  const digitGroups = text.match(/\d+/g) ?? [];
  const [firstGroup, secondGroup] = digitGroups;
  const isCompact = digitGroups.length === 1 && firstGroup?.length === COMPACT_TIME_LENGTH;
  const hourText = isCompact ? firstGroup?.slice(0, 2) : firstGroup;
  const minuteText = isCompact ? firstGroup?.slice(2) : secondGroup;
  if (hourText === undefined || minuteText === undefined || (!isCompact && digitGroups.length !== 2)) return state;
  const [hourSegment, minuteSegment] = state.segments;
  if (!hourSegment || !minuteSegment) return state;
  return {
    ...state,
    segments: [withSegmentValue(hourSegment, Number(hourText)), withSegmentValue(minuteSegment, Number(minuteText))],
  };
}
```

```ts
import type { Reducer } from '../create-store';

export interface ColumnOption<Value> {
  readonly value: Value;
  readonly label: string;
  readonly isDisabled: boolean;
}

export interface ColumnState<Value> {
  readonly options: readonly ColumnOption<Value>[];
  readonly selectedIndex: number;
}

export type ColumnEvent<Value> =
  | { readonly type: 'option.select'; readonly index: number }
  | { readonly type: 'option.step'; readonly amount: number }
  | { readonly type: 'options.replace'; readonly options: readonly ColumnOption<Value>[]; readonly preferredValue: Value };

type IsEqual<Value> = (first: Value, second: Value) => boolean;

export function createColumnState<Value>(
  options: readonly ColumnOption<Value>[],
  selectedValue: Value,
  isEqual: IsEqual<Value> = Object.is,
): ColumnState<Value> {
  const preferredIndex = options.findIndex((option) => isEqual(option.value, selectedValue));
  return { options, selectedIndex: nearestEnabledIndex(options, preferredIndex === -1 ? 0 : preferredIndex) };
}

export function columnReducer<Value>(isEqual: IsEqual<Value> = Object.is): Reducer<ColumnState<Value>, ColumnEvent<Value>, void> {
  return (state, event) => {
    switch (event.type) {
      case 'option.select':
        return state.options[event.index]?.isDisabled === false && event.index !== state.selectedIndex
          ? { ...state, selectedIndex: event.index }
          : state;
      case 'option.step':
        return withSelectedIndex(state, steppedIndex(state, event.amount));
      case 'options.replace':
        return replaceOptions(state, event.options, event.preferredValue, isEqual);
    }
  };
}

export function selectedColumnValue<Value>(state: ColumnState<Value>): Value | null {
  return state.options[state.selectedIndex]?.value ?? null;
}

function withSelectedIndex<Value>(state: ColumnState<Value>, selectedIndex: number): ColumnState<Value> {
  return selectedIndex === state.selectedIndex ? state : { ...state, selectedIndex };
}

function steppedIndex<Value>(state: ColumnState<Value>, amount: number): number {
  const direction = amount < 0 ? -1 : 1;
  let index = state.selectedIndex;
  for (let remaining = Math.abs(amount); remaining > 0; remaining -= 1) {
    const next = nextEnabledIndex(state.options, index, direction);
    if (next === null) break;
    index = next;
  }
  return index;
}

function nextEnabledIndex<Value>(options: readonly ColumnOption<Value>[], from: number, direction: 1 | -1): number | null {
  for (let index = from + direction; index >= 0 && index < options.length; index += direction) {
    if (options[index]?.isDisabled === false) return index;
  }
  return null;
}

// Goal: 연·월이 바뀌어 고른 값(예: 30일·윤달)이 사라지면 같은 자리에서 가장 가까운 선택 가능 항목으로 옮김
function nearestEnabledIndex<Value>(options: readonly ColumnOption<Value>[], preferredIndex: number): number {
  const clampedIndex = Math.min(Math.max(preferredIndex, 0), Math.max(options.length - 1, 0));
  for (let distance = 0; distance < options.length; distance += 1) {
    if (options[clampedIndex - distance]?.isDisabled === false) return clampedIndex - distance;
    if (options[clampedIndex + distance]?.isDisabled === false) return clampedIndex + distance;
  }
  return clampedIndex;
}

function replaceOptions<Value>(
  state: ColumnState<Value>,
  options: readonly ColumnOption<Value>[],
  preferredValue: Value,
  isEqual: IsEqual<Value>,
): ColumnState<Value> {
  const preferredIndex = options.findIndex((option) => isEqual(option.value, preferredValue));
  return { options, selectedIndex: nearestEnabledIndex(options, preferredIndex === -1 ? state.selectedIndex : preferredIndex) };
}
```

```ts
import type { CalendarSystem, DateFields, EpochDay, MonthCode } from '@lunisolar-picker/calendar';
import type { ResolvedConstraints } from '../constraints/resolve-constraints';
import { padDigits } from '../format-digits';
import { boundsFor, daysInVisibleMonth, fieldsOf, firstEpochDayOfMonth } from '../grid/calendar-math';
import type { LocaleData } from '../locales/locale-data';
import type { ColumnOption } from './column';
import type { TimeFieldContext } from './time-field';

export interface WheelDateColumns {
  readonly years: readonly ColumnOption<number>[];
  readonly months: readonly ColumnOption<MonthCode>[];
  readonly days: readonly ColumnOption<number>[];
}

export interface WheelTimeColumns {
  readonly hours: readonly ColumnOption<number>[];
  readonly minutes: readonly ColumnOption<number>[];
}

const LAST_HOUR = 23;
const END_OF_DAY_HOUR = 24;
const MINUTES_PER_HOUR = 60;
const TIME_PART_DIGITS = 2;

// Constraint: fields는 constrainDateFields를 거친 값이어야 함. 없는 윤달·30일이면 monthsInYear/daysInMonth가 던짐
export function buildWheelDateColumns(
  calendar: CalendarSystem,
  fields: DateFields,
  constraints: ResolvedConstraints,
  locale: LocaleData,
): WheelDateColumns {
  const bounds = boundsFor(calendar, constraints);
  const firstYear = fieldsOf(calendar, bounds.min).year;
  const lastYear = fieldsOf(calendar, bounds.max).year;
  const month = { year: fields.year, monthCode: fields.monthCode };
  const monthStart = firstEpochDayOfMonth(calendar, month);
  return {
    years: Array.from({ length: lastYear - firstYear + 1 }, (_, index) => {
      const year = firstYear + index;
      return { value: year, label: String(year), isDisabled: false };
    }),
    months: calendar.monthsInYear(fields.year).map((monthCode) => {
      const candidate = { year: fields.year, monthCode };
      const candidateStart = firstEpochDayOfMonth(calendar, candidate);
      const candidateEnd = candidateStart + daysInVisibleMonth(calendar, candidate) - 1;
      return {
        value: monthCode,
        label: locale.formatMonthName(candidate, calendar.id),
        isDisabled: candidateStart > bounds.max || candidateEnd < bounds.min,
      };
    }),
    days: Array.from({ length: daysInVisibleMonth(calendar, month) }, (_, index) => {
      const epochDay = (monthStart + index) as EpochDay;
      const isDisabled = epochDay < bounds.min || epochDay > bounds.max || constraints.isEpochDayDisabled(epochDay);
      return { value: index + 1, label: String(index + 1), isDisabled };
    }),
  };
}

export function buildTimeColumns(context: TimeFieldContext): WheelTimeColumns {
  const lastHour = context.isEndOfDayAllowed ? END_OF_DAY_HOUR : LAST_HOUR;
  const minuteCount = Math.ceil(MINUTES_PER_HOUR / context.minuteStep);
  return {
    hours: Array.from({ length: lastHour + 1 }, (_, hour) => timeOption(hour)),
    minutes: Array.from({ length: minuteCount }, (_, index) => timeOption(index * context.minuteStep)),
  };
}

function timeOption(value: number): ColumnOption<number> {
  return { value, label: padDigits(value, TIME_PART_DIGITS), isDisabled: false };
}
```

`packages/core/src/gestures/velocity-tracker.ts`:
```ts
export interface PointerSample {
  readonly position: number;
  readonly timeMs: number;
}

export interface VelocityTracker {
  add(sample: PointerSample): void;
  velocity(): number;
  reset(): void;
}

// Constraint: 손을 떼기 직전의 속도만 관성에 반영해야 해서 최근 100ms 샘플만 씀
const VELOCITY_WINDOW_MS = 100;

export function createVelocityTracker(): VelocityTracker {
  let samples: PointerSample[] = [];
  return {
    add(sample) {
      samples = [...samples, sample].filter((candidate) => sample.timeMs - candidate.timeMs <= VELOCITY_WINDOW_MS);
    },
    velocity() {
      const first = samples[0];
      const last = samples.at(-1);
      if (!first || !last || last.timeMs === first.timeMs) return 0;
      return (last.position - first.position) / (last.timeMs - first.timeMs);
    },
    reset() {
      samples = [];
    },
  };
}
```

```ts
export interface InertiaInput {
  readonly offset: number;
  readonly velocity: number;
  readonly itemSize: number;
  readonly itemCount: number;
}

export interface InertiaTarget {
  readonly index: number;
  readonly durationMs: number;
}

const DECELERATION_PX_PER_MS2 = 0.002;
const SNAP_DURATION_MS = 200;
const MIN_SETTLE_MS = 120;
const MAX_SETTLE_MS = 900;
const EASE_EXPONENT = 3;

// Goal: 등감속 운동으로 멈출 위치를 예측해 가장 가까운 항목에 맞춤. 프레임 루프는 바인딩이 돌림 (스펙 6.2)
export function projectInertia(input: InertiaInput): InertiaTarget {
  const travel = (input.velocity * Math.abs(input.velocity)) / (2 * DECELERATION_PX_PER_MS2);
  const projectedIndex = Math.round((input.offset + travel) / input.itemSize);
  const index = Math.min(Math.max(projectedIndex, 0), input.itemCount - 1);
  if (input.velocity === 0) return { index, durationMs: SNAP_DURATION_MS };
  const durationMs = Math.min(Math.max(Math.abs(input.velocity) / DECELERATION_PX_PER_MS2, MIN_SETTLE_MS), MAX_SETTLE_MS);
  return { index, durationMs };
}

export function easeOutPosition(from: number, to: number, elapsedMs: number, durationMs: number): number {
  const progress = Math.min(Math.max(elapsedMs / durationMs, 0), 1);
  return from + (to - from) * (1 - (1 - progress) ** EASE_EXPONENT);
}
```

```ts
export type EdgeDirection = 'previous' | 'next';

export interface EdgeDwell {
  enter(direction: EdgeDirection, nowMs: number): void;
  leave(): void;
  poll(nowMs: number): EdgeDirection | null;
}

// Goal: 드래그 중 달력 가장자리에 0.5초 머물면 달을 넘김 (web-console 동작과 같음)
export const EDGE_DWELL_DELAY_MS = 500;

export function createEdgeDwell(delayMs: number = EDGE_DWELL_DELAY_MS): EdgeDwell {
  let direction: EdgeDirection | null = null;
  let sinceMs = 0;
  return {
    enter(nextDirection, nowMs) {
      if (nextDirection === direction) return;
      direction = nextDirection;
      sinceMs = nowMs;
    },
    leave() {
      direction = null;
    },
    poll(nowMs) {
      if (direction === null || nowMs - sinceMs < delayMs) return null;
      sinceMs = nowMs;
      return direction;
    },
  };
}
```
